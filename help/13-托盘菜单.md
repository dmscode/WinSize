托盘菜单
========

右键任务栏上的 WinSize 图标，就是程序的操作面板。菜单项可以自己排、自己删。

## 默认菜单

从上到下：

| 菜单项 | 作用 |
| --- | --- |
| 设置 | 打开设置页 |
| 辅助线 | 开关，显示时前面有勾 |
| 悬停激活 | 开关，显示时前面有勾 |
| 置顶 | 当前窗口置顶开关 |
| 重载 | 重读 `Config.ini` |
| 重启 | 重启程序 |
| 帮助 | 打开帮助文档 |
| 打开日志 | 用默认程序打开 `Debug.log` |
| 退出 | 关闭程序 |

分隔线把操作和退出隔开，避免手滑点到退出。

## 勾选状态

带勾的菜单项是开关类动作，勾表示现在是开着的：

- 辅助线：勾表示线正在显示。
- 悬停激活：勾表示正在运行。
- 置顶：勾表示该窗口已置顶。

菜单的勾是每次打开时现算的，不会过期。

## 自己排

设置页 → 托盘。一条一行，从上到下就是菜单从上到下。

能写三类：

| 写法 | 含义 | 例子 |
| --- | --- | --- |
| `-` | 分隔线 | `-` |
| `cmd:<命令>` | 内建命令 | `cmd:settings` |
| `act:<动作>\|<参数>` | 任意已注册的动作 | `act:guides`、`act:guides\|h` |

### 内建命令

| 命令 | 作用 |
| --- | --- |
| `cmd:settings` | 打开设置页 |
| `cmd:reload` | 重读配置 |
| `cmd:restart` | 重启程序 |
| `cmd:help` | 打开帮助 |
| `cmd:openLog` | 打开日志文件 |
| `cmd:exit` | 退出 |

### 动作项

`act:` 后面跟动作名，和按键里用的是同一套，见 [05 按键绑定](./05-按键绑定.md)。

- 不带参数表示开关，比如 `act:guides`。
- 带参数表示执行该模式，比如 `act:guides|h` 只显示横线。

## 两条硬规定

“设置”和“退出”删不掉。保存时如果缺了它们，程序会自动补回去，设置放最上面，退出放最下面。

原因很直接：设置页从托盘进，退出也只能从托盘进。删掉任何一个，就只能去任务管理器。

非法条目会被整批拒绝。写了不认识的动作名，或者 `cmd:不存在`，保存时会报错并指出是哪一行。

## 什么时候用它

| 场景 | 说明 |
| --- | --- |
| 不知道该按哪个键 | 菜单里有中文名称 |
| 一次性操作 | 打开日志、看版本、重启 |
| 想确认状态 | 辅助线、悬停有没有在跑，看勾 |

菜单可以自定义，所以你现在看到的可能和上表不一样。默认就是上表。
