配置文件
========

所有设置都在 `Config.ini` 里，位置在 **exe 同目录**。它是纯文本，可以直接改，
也可以用设置页改——设置页改的就是这个文件。

## 先记住三条

**1. 文件不存在时用内置默认值。**
删掉 `Config.ini` 再启动，程序会按默认值运行（九个方案、九个按键、九个鼠标区）。
想从零开始，删掉它比逐条清空更快。

**2. 手改之后要重载。**
程序不会盯着文件看。改完在等待态按 `R`，或托盘菜单 → 重载。

**3. 存成 UTF-8。**
文件带 BOM（`UTF-8 with BOM`），Windows 记事本默认就是这个。存成 ANSI 会让中文路径变乱码，
表现为"排除规则突然不生效了"。

改之前建议复制一份 `Config.ini.bak`。程序自己也会在写入前生成 `Config.ini.bak`。

## 哪些东西会存进这里

| 会存 | 不会存 |
| --- | --- |
| 布局方案、按键、九宫格映射、托盘菜单 | 辅助线现在显不显示 |
| 排除列表 | 悬停激活现在跑不跑（只有"启动时是否自动跑"会存） |
| 插件开关与参数 | 窗口置顶状态 |
| 开机自启之外的偏好 | 上一次的撤销记录 |
| 窗口绑定的槽位 | — |

判断标准很简单：**跨会话还有意义的东西才存**。临时的开关状态一律只在内存里，
重启就回到初始值。

## 节一览

```ini
[Meta]          配置结构版本（程序维护，不用管）
[Help]          帮助页地址
[Plugins]       插件总开关
[Plugins.xxx]   各插件的私有参数
[Switch]        全局功能开关
[Layout]        布局方案
[Keys]          按键绑定
[QuickLayout]   九宫格 → 方案
[Tray]          托盘菜单
[Exclusions]    窗口排除
[Server]        本地服务参数
```

顺序无所谓，节名大小写不敏感。

## [Meta]

```ini
[Meta]
ConfigVersion = 1
```

程序用来判断配置结构是否需要迁移。**不要手改**。

## [Help]

```ini
[Help]
Page = https://example.com/my-winSize-help
```

按 `H` 时打开的地址。不写这一节（或留空）时用程序内置的默认值——
它是随版本走的，所以这里不抄一遍，避免两处对不上。可以改成你自己的笔记、
公司 wiki，或者本地文件：

```ini
Page = file:///D:/Docs/WinSize%E5%BF%AB%E6%8D%B7%E9%94%AE.md
```

不写这一节时，用内置的默认地址（就是上面那个）。

## [Plugins]

```ini
[Plugins]
capsTip = 1
dragGrid = 1
guides = 1
winBind = 1
hover = 1
```

| 键 | 插件 | 写 0 的后果 |
| --- | --- | --- |
| `capsTip` | 大写提示 | 按 CapsLock 不再提示，恢复系统原生行为 |
| `dragGrid` | 拖拽调整 | `LAlt + 右键` 手势失效 |
| `guides` | 辅助线 | `G` 等键失效 |
| `winBind` | 窗口绑定 | 数字键失效，已存的槽位不再加载 |
| `hover` | 悬停激活 | `T` 失效 |

**没列出的视为启用。** 所以想全部打开，把这个节清空就行。

> 关掉插件后，它提供的动作也消失了。如果 `[Keys]` 里还有键引用它，
> 那个键按下会提示 `Error Action`，日志里会记一条"按键绑定无效"。

## [Plugins.xxx]

每个插件自己的参数，程序核心不解析，由插件读。详见各功能文档：

| 节 | 参数 | 见 |
| --- | --- | --- |
| `[Plugins.DragGrid]` | 网格密度、透明度、顶部标题栏 / 右上角置顶 | [04](./04-鼠标手势.md) |
| `[Plugins.Guides]` | 线宽、颜色、透明度、缺口 | [10](./10-辅助线.md) |
| `[Plugins.Hover]` | 停留时长、启动时是否自动跑 | [11](./11-悬停激活.md) |
| `[Plugins.WinBind]` | 槽位表（程序自动写） | [09](./09-窗口绑定.md) |

`[Plugins.WinBind]` 长这样，**不需要手写**：

```ini
[Plugins.WinBind]
1 = 132416|D:\Apps\Zed\zed.exe|Zed|main.rs - Zed
```

格式是 `句柄|进程路径|窗口类|标题`。删掉某一行就等于解绑那个槽位。

## [Switch]

全局开关，`1` 开、`0` 关。可以只写要改的项，没写的保持默认。

| 键 | 默认 | 说明 |
| --- | --- | --- |
| `logError` | 1 | 写 `Debug.log`。关掉后只记错误，不记普通信息 |
| `CapsTip` | 1 | 旧键，已下放为插件；值会被迁移一次，保留仅为兼容 |
| `ShowTime` | 1 | 等待条显示当前时间，而不是 `WAITING` |
| `QuickLayout` | 1 | 鼠标手势总开关（九宫格 + 拖框） |
| `MultiDpi` | 1 | 混合 DPI 时跳过阴影补偿（见下） |
| `AutoCheckUpdate` | 1 | 自动检查更新。关掉后托盘不再提示新版本，设置页仍可手动检查 |

**关于 `MultiDpi`**：各屏缩放比例不一致时，程序默认不去猜 DWM 阴影的厚度，
直接按像素算——这样位置更准。各屏缩放一致时仍会正常补偿。
除非你遇到"窗口总是偏几像素"，否则不用动它。

启动时如果 `[Switch]` 缺了某个键，程序会自动补上默认值（只补开关，不补布局/按键，
因为删掉一个布局是意图，补回去等于篡改）。

## [Layout]

```ini
[Layout]
LeftTop     = 0|0|50sw|50sh
MyWide      = 0|0|70sw|100sh
```

名字在等号左边，规则在右边。写法见 [03 布局方案](./03-布局方案.md)。

> **这一节是整体覆盖**：文件里有 `[Layout]`，内置的九个默认方案就全部失效。
> 想保留默认值，就要把它们一起写进来。

## [Keys]

```ini
[Keys]
Q = Layout|LeftTop
P = Pin
1 = WinBind|1
```

`键 = 动作|参数`。同样是整体覆盖。详见 [05 按键绑定](./05-按键绑定.md)。

## [QuickLayout]

九宫格的九个格子各对应哪个方案：

```ini
[QuickLayout]
1 = LeftTop
2 = FullTop
...
```

多显示器还能写两位编号（`21` = 2 号屏左上），查找顺序见 [04](./04-鼠标手势.md)。

## [Tray]

托盘菜单，**行的顺序就是菜单顺序**：

```ini
[Tray]
1 = cmd:settings
2 = -
3 = act:guides
4 = act:hover
5 = act:pin
6 = -
7 = cmd:reload
8 = cmd:restart
9 = cmd:help
10 = cmd:openLog
11 = -
12 = cmd:exit
```

| 写法 | 含义 |
| --- | --- |
| `-` | 分隔线 |
| `cmd:xxx` | 内建命令 |
| `act:动作\|参数` | 任意已注册动作 |

「设置」与「退出」必填，删了会被自动补回。详见 [13 托盘菜单](./13-托盘菜单.md)。

## [Exclusions]

窗口排除规则。**默认是空节**（节在，但一条规则都没有），用 `U` 键排除时程序往里写：

```ini
[Exclusions]
1 = D:\Program Files\Microsoft VS Code\Code.exe|Chrome_WidgetWin_1
```

`进程|窗口类`，两段都可以留空。详见 [07 窗口排除](./07-窗口排除.md)。

## [Server]

```ini
[Server]
IdleMs = 0
```

本地 HTTP 服务的空闲时长（毫秒）。**默认 `0` = 永不关**：程序一启动就监听，
AI / 脚本随时调得到。想让它在没人用时收摊，写 `300000`（5 分钟）。
详见 [16 第三方调用](./16-第三方调用.md)。

## 手改出错会怎样

| 错误 | 后果 |
| --- | --- |
| 布局规则写坏 | 那个方案按下没反应；按 `R` 时提示 `Bad Layout`，日志里有方案名与原值 |
| 按键引用了不存在的动作 | 那个键提示 `Error Action`，日志里有键名与原因 |
| 整个节写坏（比如少了 `[`） | 该节读不到，回退默认值 |
| 存成 ANSI 编码 | 中文路径乱码，排除规则失效 |

**日志在 exe 同目录的 `Debug.log`**，托盘菜单「打开日志」可以直接打开。
遇到"按了没反应"，第一件事是看它。
