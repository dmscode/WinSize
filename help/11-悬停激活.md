悬停激活
========

鼠标在某个窗口上停留一会儿，就把那个窗口切到前面——不用点。

**默认不运行。** 它会在你不经意时抢焦点，所以出厂是关的，需要你主动按一下打开。

## 怎么开关

| 操作 | 结果 |
| --- | --- |
| 双击 Alt 按 `T` | 开始 / 暂停（这是临时开关，**不写入配置**） |
| 冒号指令 `hv` | 同上 |
| 托盘菜单里的「悬停激活」 | 同上，菜单项会打勾表示"正在跑" |
| 设置页 → 插件 → 悬停激活 → **启动时自动开始** | 决定程序启动后是否直接进入运行状态 |

三个入口改的是同一件事：**现在跑不跑**。只有设置页那个勾选框会被记住。

## 和"勾选插件"的区别

设置页插件区每一行前面有个勾选框，它控制的是**加载不加载这个插件**：

| 勾选框 | 含义 |
| --- | --- |
| 勾上 | 插件加载，`T` 键可用，但**默认仍然不跑** |
| 取消 | 插件完全不加载，`T` 键也没了 |

所以"勾着但不出效果"是正常的——还要按一下 `T` 才算真的开始。

## 它会做什么

| 行为 | 说明 |
| --- | --- |
| 停留多久算数 | 默认 800 毫秒，可调 300~5000 |
| 怎么激活 | 把窗口切到前台（同点一下它的标题栏） |
| 移动窗口吗 | 不动，只切焦点 |
| 同一个窗口会反复抢吗 | 不会。**一次悬停只打扰一次**，鼠标移开再回来才会再触发 |
| 被排除的窗口 | 不参与 |
| 管理员窗口 | 切不过去，只记日志，不弹提示（弹提示比不激活更烦） |

### 打字时不会打断你

最近 **1 秒内有过键盘输入就不激活**。

这一条是为了解决输入法被打断：你正在打字时鼠标往往静止停在某个窗口上，
没有这道保护的话，每 0.8 秒就会把那个窗口激活一次，输入法的组合串反复被切断。

所以它的实际语义是："你停手超过 1 秒，且鼠标还在同一个窗口上，才认为你在看它。"

## 什么时候会用到

| 场景 | 说明 |
| --- | --- |
| 多窗口对照阅读 | 鼠标移到哪个窗口就读哪个，不用点 |
| 一边看资料一边写 | 移过去看一眼，移回来接着写 |
| 不喜欢点窗口标题栏 | 纯手势操作 |

反过来说，如果你的鼠标经常停在窗口上（比如远控、录屏讲解），它会很烦——那就别开。

## 参数

设置页 → 插件 → 悬停激活：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 停留时长 | 800 毫秒 | 300~5000。太小会把"鼠标划过"当成停留 |
| 启动时自动开始 | 关 | 打开后，程序启动即在后台待命 |
