鼠标手势
========

按住左 Alt，再按右键，在窗口上做一个动作：

| 动作 | 结果 |
| --- | --- |
| 原地轻点，几乎不移动 | 按鼠标所在的九宫格位置套用布局 |
| 按住并拖出一个框 | 窗口跟着框走，两端自动贴齐网格 |

同一个手势，用“有没有移动”来区分。默认开启。

## 轻点：九宫格

把窗口当成九宫格，鼠标落在哪一格，就用哪一格的方案：

```
1 2 3        左上  顶部  右上
4 5 6   ⇔    左侧  居中  右侧
7 8 9        左下  底部  右下
```

按住左 Alt，在窗口右下角点一下右键，窗口就贴到右下四分之一。

九个格子分别调用哪个方案，在设置页的“快速布局”区改，也可以直接写 `Config.ini` 的 `[QuickLayout]`。

### 什么算轻点

按下到松开之间，鼠标移动不超过 30 像素，横竖都算，就算轻点。超过 30 像素进入拖框。

这里用的是原始位移，不是对齐后的矩形。否则在同一个格子里挪 40 像素，两端会吸到同一条网格线，框变成 0×0，反而被误判成轻点。

### 多显示器的格子编号

单屏时格子号是 1 到 9。多屏时，程序会把显示器号和格号拼起来查找：

> 在第 2 块屏的中间松手，编号是 `25`

然后按这个顺序找方案：

1. `20`：这块屏的全局方案，2 号屏的所有格子都用它。
2. `25`：正好对应的那一格。
3. `5`：通用的九宫格方案，也就是单屏时的九个。
4. 都没有，就什么都不做。

这样你可以给小副屏配一个“不管点哪都铺满”的方案（`20 = FullScreen`），主屏继续用正常九宫格。不确定就别配，第 3 步会兜住。

## 拖动：自由框选

按住左 Alt 和右键拖动，屏幕上会出现网格和一个半透明选区。松开右键，窗口落到选区里。

- 网格：默认按工作区自动计算，18 列 × 12 行，让窗口对齐到同一套线。
- 对齐：选区的四条边分别吸附到最近的网格线。
- 标记：拖动时显示下面几层窗口的边框，方便避开或对齐，默认显示 3 个。
- 超出边界：选区可以拉到屏幕外，窗口也会跟着出去一部分。

## 窗口装饰（可选）

同样按住左 Alt 和右键，但点在窗口顶部时，做的是处理窗口的边框，不是布局。

两个开关互相独立，默认都关闭，可以只开一个：

| 开关 | 作用 |
| --- | --- |
| 顶部切换标题栏 | 点窗口顶部，隐藏或恢复标题栏 |
| 右上角切换置顶 | 点窗口右上角，置顶或取消置顶 |

### 优先级

1. 开了“右上角切换置顶”，并且点在右上角：置顶。
2. 否则，开了“顶部切换标题栏”，并且点在顶部：隐藏或恢复标题栏。
3. 都不命中：走九宫格。

三种组合的实际效果：

| 配置 | 点顶部会发生什么 |
| --- | --- |
| 只开置顶 | 右上角那一块置顶，其余顶部仍然走九宫格 |
| 只开标题栏 | 整个顶部条，包括右上角，都用来切换标题栏 |
| 两个都开 | 右上角优先置顶，其余顶部切换标题栏 |

“置顶热区宽度”默认 45 像素，只在开了置顶时生效，决定右上角多宽算置顶区。

### 切换标题栏

隐藏后，窗口总尺寸不变，客户区会自动长高一个标题栏的高度，内容铺满。再点一次原位置就恢复。

### 只对当前窗口生效

后台窗口点不出反应。先把目标窗口切到前台，点一下它的任意位置，再按 `Alt + 右键`。

### 浏览器和 Electron 应用不能隐藏标题栏

窗口带着 `WS_CAPTION` 样式位，不代表它真的画了系统标题栏。

Chrome、Edge、VS Code、各种聊天工具都带着这个样式位。它们留着它是为了阴影、缩放和 Aero Snap，但标题栏是自己画在内容区里的。系统没有画那一条，也就没有东西可以隐藏。

程序的判断依据是客户区顶边到窗口顶边的距离：

| 窗口 | 差值 | 结果 |
| --- | --- | --- |
| 原生 Win32，比如资源管理器、记事本 | 约 33 像素 | 可以隐藏 |
| 浏览器 / Electron | 约 9 像素，只剩阴影边框 | 不处理 |

对第二种窗口，点顶部仍然走九宫格。那一条带其实是它自己的标签栏，用户点它是想布局，程序不会弹“不支持”来打扰。

硬去掉这类窗口的样式位，只会掉一层阴影边框，标题栏还在，窗口还会变得拖不动。所以这里是主动拒绝，不是做不到。

置顶不受这个限制，跟标题栏没关系，任何窗口都能置顶。所以建议至少开“右上角切换置顶”。

### 退出时会还原

被隐藏的标题栏会在停用插件、重载配置或退出程序时自动还原，不会留下永远没有标题栏的窗口。

不想自动还原，可以在设置里关掉“退出时还原标题栏”。关掉后需要你自己再点一次恢复。

### 开关在哪

设置页 → 插件 → 拖拽调整 → “顶部切换标题栏” / “右上角切换置顶”。

两个都默认关闭。都关掉后，这部分功能完全不存在，九宫格的行为和没有它时一样。

## 手势配置

设置页 → 插件 → 拖拽调整：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 网格自适应 | 开 | 按工作区计算网格密度；关掉后用固定列数和行数 |
| 列数 / 行数 | 18 / 12 | 只在关闭网格自适应时生效 |
| 其它窗口边框 | 3 | 拖动时显示几个下层窗口的边框，0 表示不显示 |
| 顶部切换标题栏 | 关 | 点窗口顶部隐藏或恢复标题栏，只对原生标题栏生效 |
| 右上角切换置顶 | 关 | 点窗口右上角置顶或取消置顶 |
| 置顶热区宽度 | 45 | 右上角多宽算置顶区，只在开了置顶时有效 |
| 退出时还原标题栏 | 开 | 只还原被隐藏的标题栏，置顶本来就不记录 |
| 网格透明度 | 110 | 0~255，越小越淡 |
| 标记透明度 | 220 | 选区和边框的透明度 |

## 整体关闭

设置页 → 常规 → 取消“快速布局”。

这个开关是整套鼠标手势的总闸。关掉后不只九宫格失效，拖框调整也不再响应，`LAlt + 右键` 会还原成程序原本的行为。想保留拖框、只关九宫格，目前做不到，因为两者用的是同一个热键。

## 和双击 Alt 的区别

| 方式 | 触发 | 作用窗口 |
| --- | --- | --- |
| 键盘 | 双击左 Alt，再按键 | 双击时的前台窗口 |
| 鼠标手势 | 左 Alt + 右键 | 右键点到的窗口，不必是前台窗口 |

鼠标手势的好处是不用先切窗口。看到哪个窗口，直接按在它身上就行。
