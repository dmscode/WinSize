鼠标手势
========

按住**左 Alt**、按**右键**，在窗口上做一个动作：

| 你做的动作 | 结果 |
| --- | --- |
| 原地**轻点**（几乎没移动） | 按鼠标所在的九宫格位置套用布局 |
| **按住拖动**出一个框 | 窗口跟着你框的范围走，两端自动贴齐网格 |

同一个手势，靠"移动了没有"分流。默认开启。

## 轻点：九宫格布局

把窗口当成九宫格，鼠标落在哪一格，就套用那一格的方案：

```
1 2 3        左上  顶部  右上
4 5 6   ⇔    左侧  居中  右侧
7 8 9        左下  底部  右下
```

按住左 Alt → 在窗口的右下角点一下右键 → 窗口贴到右下四分之一。

九个格子分别调用哪个方案，在设置页的**快速布局**区改；也可以直接写 `Config.ini` 的 `[QuickLayout]`。

### 判定"轻点"的标准

按下到松开之间，鼠标移动**不超过 30 像素**（横竖都算）就算轻点。超过就进入拖框。

用的是原始位移，不是对齐后的矩形——否则在同一个格子里挪 40 像素，两端会吸到同一条网格线，
框变成 0×0，反而被误判成"轻点"。

### 多显示器的格子编号

单屏时格子号是 1~9。多屏时，实际查找的编号是"显示器号 + 格号"：

> 在第 2 块屏的中间松手 → 编号 `25`

然后按这个顺序找方案，找到就用：

1. `20` —— 这块屏的"全局方案"（2 号屏的所有格子都用它）
2. `25` —— 正好对应的那格
3. `5` —— 通用户九宫格方案（就是单屏时的那九个）
4. 都没有 → 什么都不做

这让你可以给一块小副屏设"不管点哪都铺满"（配 `20 = FullScreen`），
而主屏继续用正常九宫格。不确定就别配，第 3 步会兜住。

## 拖动：自由框选

按住左 Alt + 右键**拖动**，屏幕上出现网格与一个半透明选区，松开右键窗口就落到选区里。

- **网格**：默认按工作区自动算（18 列 × 12 行），让所有窗口天然对齐到同一套线。
- **对齐**：选区的四个边各自吸附到最近的网格线。
- **标记**：拖动时会显示出下面几层窗口的边框，方便你避开或对齐它们（默认显示 3 个）。
- **超出边界**：选区可以被拉到屏幕外，窗口也会跟着出去一部分。

## 窗口装饰操作（可选，两个独立开关，默认都关）

同样按住左 Alt + 右键，但点在窗口**顶部**时，做的是"处理这个窗口的框"，不是布局。

两个开关**各管各的**，可以只开一个：

| 开关 | 管什么 |
| --- | --- |
| **顶部切换标题栏** | 点窗口顶部一条 → 隐藏 / 恢复标题栏 |
| **右上角切换置顶** | 点窗口右上角 → 置顶 / 取消置顶 |

### 优先级：置顶 > 标题栏 > 九宫格

1. 开了「右上角切换置顶」，且正好点在右上角 → **置顶**；
2. 否则，开了「顶部切换标题栏」，且点在顶部那一条 → **隐藏 / 恢复标题栏**；
3. 都不命中 → **九宫格**。

所以三种组合的实际效果是：

| 你怎么配 | 点顶部会发生什么 |
| --- | --- |
| 只开置顶 | 右上角那一块置顶；**其余顶部仍然走九宫格** |
| 只开标题栏 | **整个顶部条（含右上角）**都用来切标题栏 |
| 两个都开 | 右上角优先置顶，其余顶部切标题栏 |

「置顶热区宽度」（默认 45 像素）只在开了置顶时才有意义，它决定右上角多宽算作置顶区。

### 切换标题栏

隐藏后，窗口**总尺寸不变、客户区自动长高**一个标题栏的高度，内容铺满——不是把窗口缩小。
再点一次原位置就恢复。

### 只对当前窗口生效

后台窗口点不出反应——必须先切到那个窗口（点一下它的任意位置），再按 `Alt + 右键`。

### 只有真的画了系统标题栏的窗口才响应

这是这一块最容易误解的地方：**`WS_CAPTION` 这个样式位，不代表窗口真的画了标题栏。**

浏览器（Chrome、Edge、brave）、Electron 应用（VS Code、各种聊天工具）都带着这个样式位——
它们留着它是为了窗口阴影、缩放和 Aero Snap，但标题栏是**它们自己画在内容区里**的。
系统根本没画那一条，所以没有东西可以隐藏。

程序的判据是：**客户区顶边到窗口顶边的距离**。

| 窗口 | 差值 | 结果 |
| --- | --- | --- |
| 原生 Win32（资源管理器、Directory Opus、记事本…） | ≈33px | 可隐藏 |
| 浏览器 / Electron | **9px**（只剩阴影边框） | 不处理 |

对第二种窗口，点顶部**仍然是九宫格**（那一条带其实是它自己的标签栏，用户点它是想布局），
不会弹"不支持"来打扰你。

> 如果硬要去掉它们的样式位，结果会是：掉一层 9px 阴影边框、**标题栏还在**，
> 而窗口变成拖不动（没有抓手）——比不做更糟。所以这里是主动拒绝，不是能力不足。

**置顶不受这个限制**：它跟标题栏没关系，任何窗口都能置顶。这也是建议至少开「右上角切换置顶」的原因。

### 退出时会还原

被隐藏的标题栏会在**停用插件 / 重载配置 / 退出程序**时自动还回去，
不会留下"永远没有标题栏"的窗口。

不想让它自动还原，可以在设置里关掉「退出时还原标题栏」——但那样你需要自己再点一次恢复。

### 开关在哪

设置页 → 插件 → **拖拽调整** → 「顶部切换标题栏」/「右上角切换置顶」。

两个都默认关闭。都关掉后这部分**完全不存在**，九宫格的行为与没有它时一模一样。

## 相关配置

设置页 → 插件 → **拖拽调整**：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 网格自适应 | 开 | 按工作区计算网格密度；关掉则用固定的列数/行数 |
| 列数 / 行数 | 18 / 12 | 网格自适应关闭时才生效 |
| 其它窗口边框 | 3 | 拖动时显示几个下层窗口的边框；0 = 不显示 |
| 顶部切换标题栏 | 关 | 点窗口顶部隐藏/恢复标题栏（只对原生标题栏生效） |
| 右上角切换置顶 | 关 | 点窗口右上角置顶/取消置顶 |
| 置顶热区宽度 | 45 | 右上角多宽算「置顶区」；只在开了置顶时有效 |
| 退出时还原标题栏 | 开 | 只还原被隐藏的标题栏；置顶本来就不记录 |
| 网格透明度 | 110 | 0~255，越小越淡 |
| 标记透明度 | 220 | 选区与边框的透明度 |

## 整体关掉

设置页 → 常规 → 取消**快速布局**。

> 这个开关是**整套鼠标手势的总闸**：关掉后不仅九宫格失效，拖框调整也不再响应
> （`LAlt + 右键` 会还原成程序原本的行为）。想留拖框、只关九宫格，目前做不到——
> 两者的热键是同一个。

## 和"双击 Alt"的区别

| | 触发 | 作用于 |
| --- | --- | --- |
| 键盘 | 双击左 Alt → 按键 | 双击时的前台窗口 |
| 鼠标手势 | 左 Alt + 右键 | 右键点到的那个窗口（不必是前台窗口） |

鼠标手势的好处是**不用先切窗口**：看到哪个窗口，直接按在它身上就行。
