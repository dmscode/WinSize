按键绑定
========

决定"在等待态按哪个键，做什么事"。默认已经配好一套，改不改都行。

## 写法

`Config.ini` 的 `[Keys]` 节，一行一个：

```ini
Q = Layout|LeftTop
P = Pin
1 = WinBind|1
G = Guides
```

格式是：

```
键 = 动作名|参数
```

- 动作名大小写不敏感（`Layout` / `layout` 都行）。
- `|参数` 只在动作需要参数时才写。写多余参数会被忽略，缺必需参数会被拒绝。
- 一行只认**第一个** `=` 作为分隔符，所以等号键要写成 `Equal`。

## 可用动作

### 核心动作

| 动作 | 参数 | 作用 |
| --- | --- | --- |
| `Layout` | 方案名 | 套用某个布局（如 `Layout\|Center`） |
| `ApplyRect` | `x,y,w,h` | 按绝对像素摆放，给外部程序/脚本用 |
| `Pin` | 无 | 窗口置顶 / 取消置顶 |
| `Exclude` | 无 | 排除当前窗口 / 取消排除 |
| `Reload` | 无 | 重读配置 |
| `Reboot` | 无 | 重启程序 |
| `Help` | 无 | 打开帮助 |
| `Version` | 无 | 显示版本 |
| `Settings` | 无 | 打开设置页 |

### 插件提供的动作

| 动作 | 参数 | 作用 |
| --- | --- | --- |
| `Guides` | 空 / `h` / `v` / `x` | 辅助线：开关 / 只要横线 / 只要竖线 / 十字 |
| `Hover` | 无 | 悬停激活：开始 / 暂停 |
| `WinBind` | `0`~`9` | 绑定或唤回该槽位 |
| `WinUnbind` | `0`~`9` | 强制解绑该槽位 |
| `CapsTip` | 无 | 大写提示的开关 |

> 插件被关掉（`[Plugins]` 里写 `0`）时，它提供的动作会消失。
> 此时按键里若还引用它，启动日志会记一条"按键绑定无效"，按下时提示 `Error Action`。

### 别名

有些动作用别名更顺手，尤其在冒号指令里（见 [06](./06-冒号指令.md)）：

| 动作 | 可用别名 |
| --- | --- |
| `Layout` | `layout.apply` |
| `Settings` | `set`、`opt`、`option` |
| `Guides` | `guide`、`g` |
| `Hover` | `hv` |
| `WinBind` | `wb`、`w` |
| `WinUnbind` | `wu` |

## 能用哪些键

| 类别 | 说明 |
| --- | --- |
| 26 个字母 | **始终可用**。配置文件里没绑的键也会被吃掉，只提示 `No Action.` |
| 数字 `0`~`9` | 可用（默认给了窗口绑定） |
| 标点 | 可用，但要注意写法，见下 |
| 功能键 | 可用（`F1`~`F12`、`Insert` 等），写了才会注册 |

### 标点键的写法

`[Keys]` 的每一行按第一个 `=` 切分，所以 `=` 键本身不能直接写，要用 AHK 的键名：

```ini
Equal = Guides|x
-     = Guides|h
\     = Guides|v
```

常用键名：`Equal`（=）、`Minus`（-）、`Backslash`（\）、`Semicolon`（;）、`Comma`（,）、
`Period`（.）、`Slash`（/）、`Space`、`Tab`、`Escape`。

> 完整键名表见 AutoHotkey 文档的 Key List。写错键名不会崩，但日志里会有一条
> "按键绑定无法注册"，这个键不生效。

### 不能用的键

| 键 | 原因 |
| --- | --- |
| 左 Alt | 它是唤出等待态的触发键 |
| 鼠标键 | 鼠标手势是固定的一套（[04](./04-鼠标手势.md)） |
| `Shift + ;` | 冒号指令的引导符（[06](./06-冒号指令.md)） |

## `[Keys]` 是整体覆盖

文件里有 `[Keys]` 节，就**完全替换**内置默认表。

这意味着：想只改一个键，也得把其它键一起写上，否则其余键会全部变成"未绑定"。
**用设置页改更安全**——它会把完整表写回去。

## 用设置页改（推荐）

托盘 → 设置 → **按键**：

1. 页面上有一张键盘图，点哪个键就在下面改它。
2. 选动作、填参数（选 `Layout` 时参数是一个下拉框，列出所有方案名）。
3. 保存。

保存时会做校验，任何一项不合法就**整批拒绝**，并指出是哪个键：

| 会被拒绝的写法 | 原因 |
| --- | --- |
| `Q = Layout` | 缺参数（布局动作必须给方案名） |
| `Q = Layout\|Center2` | 没有这个方案 |
| `1 = WinBind\|10` | 槽位只能是单个数字 |
| `G = Guides\|zz` | 参数只能是 `h` / `v` / `x` |
| `X = NotAnAction` | 没有这个动作 |

删除某个键的绑定：在设置页把动作选成"（无）"，保存后该键就从配置里消失。

## 冲突与优先级

- 同一个键写两行（重复键），以**最后一行**为准。
- 按键只在**等待态**（双击 Alt 之后 3 秒内）生效，平时完全不拦截键盘。
- 大小写不影响：`q` 和 `Q` 是同一个键。
