按键绑定
========

这里决定等待态按哪个键、做什么事。默认已经配好一套，不改也能用。

## 写法

配置在 `Config.ini` 的 `[Keys]` 节，一行一个：

```ini
Q = Layout|LeftTop
P = Pin
1 = WinBind|1
G = Guides
```

格式是：

```
键 = 动作名|参数
```

动作名不区分大小写，`Layout` 和 `layout` 都行。`|参数` 只在动作需要参数时写，多余的参数会被忽略，缺少必需参数会被拒绝。

一行只把第一个 `=` 当分隔符，所以等号键要写成 `Equal`。

## 可用动作

### 核心动作

| 动作 | 参数 | 作用 |
| --- | --- | --- |
| `Layout` | 方案名 | 套用某个布局，比如 `Layout\|Center` |
| `ApplyRect` | `x,y,w,h` | 按绝对像素摆放，比如 `ApplyRect\|0,0,800,600` |
| `Pin` | 无 | 窗口置顶 / 取消置顶 |
| `Exclude` | 无 | 排除当前窗口 / 取消排除 |
| `Reload` | 无 | 重读配置 |
| `Reboot` | 无 | 重启程序 |
| `Help` | 无 | 打开帮助 |
| `Version` | 无 | 显示版本 |
| `Settings` | 无 | 打开设置页 |
| `Quit` | 无 | 退出程序，和托盘「退出」是同一条路（会删掉 `runtime.json`、释放端口） |

### 插件动作

| 动作 | 参数 | 作用 |
| --- | --- | --- |
| `Guides` | 空 / `h` / `v` / `x` | 辅助线开关 / 只开横线 / 只开竖线 / 十字 |
| `Hover` | 无 | 悬停激活开始 / 暂停 |
| `WinBind` | `0`~`9` | 绑定或唤回该槽位 |
| `WinUnbind` | `0`~`9` | 强制解绑该槽位 |
| `CapsTip` | 无 | 大写提示开关 |
| `WSwitch` | 无 | 切到下一个窗口，和全局快捷键 `Alt+反引号` 是同一个动作 |
| `WSwitchRev` | 无 | 切回上一个窗口，对应 `Shift+Alt+反引号` |

`ApplyRect` 与 `Layout` 的区别：`Layout` 走百分号布局串（`50sw` 这种），按屏幕比例算；`ApplyRect` 直接给像素，四个数缺一不可，宽高必须大于 0。

插件被关掉时（`[Plugins]` 里写 `0`），它提供的动作会消失。按键里如果还引用它，启动日志会记一条“按键绑定无效”，按下时提示 `Error Action`。

### 别名

有些动作可以用更短的别名，尤其在冒号指令里：

| 动作 | 别名 |
| --- | --- |
| `Layout` | `layout.apply` |
| `Settings` | `set`、`opt`、`option` |
| `Guides` | `guide`、`g` |
| `Hover` | `hv` |
| `WinBind` | `wb`、`w` |
| `WinUnbind` | `wu` |

## 能用哪些键

| 类别 | 说明 |
| --- | --- |
| 26 个字母 | 始终可用。配置文件里没绑的键也会被吃掉，只提示 `No Action.` |
| 数字 `0`~`9` | 可用，默认给了窗口绑定 |
| 标点 | 可用，写法见下 |
| 功能键 | 可用，比如 `F1`~`F12`、`Insert`，写了才会注册 |

### 标点键的写法

`[Keys]` 每行按第一个 `=` 切分，所以 `=` 键本身不能直接写，要用 AHK 的键名：

```ini
Equal = Guides|x
-     = Guides|h
\     = Guides|v
```

常用键名：`Equal`（=）、`Minus`（-）、`Backslash`（\）、`Semicolon`（;）、`Comma`（,）、`Period`（.）、`Slash`（/）、`Space`、`Tab`、`Escape`。

完整键名表见 AutoHotkey 文档的 Key List。写错键名不会崩，但日志里会有一条“按键绑定无法注册”，这个键不生效。

### 不能用的键

| 键 | 原因 |
| --- | --- |
| 左 Alt | 它是唤出等待态的触发键 |
| 鼠标键 | 鼠标手势是固定的一套，见 [04](./04-鼠标手势.md) |
| `Shift + ;` | 冒号指令的引导符，见 [06](./06-冒号指令.md) |

## `[Keys]` 是整体覆盖

文件里有 `[Keys]` 节，就会完全替换内置默认表。

想只改一个键，也要把其它键一起写上，否则其余键会全部变成未绑定。用设置页改更安全，它会把完整表写回去。

## 用设置页改

托盘 → 设置 → 按键：

1. 页面上有一张键盘图，点哪个键，就在下面改它（灰色的键不能绑）。
2. 选动作。需要参数的动作，右边有个文本框要手填——布局名、槽位号都填在这里；可用的方案名在设置页的指令面板里列着。
3. 保存。

保存时会校验，任何一项不合法都会整批拒绝，并指出是哪个键：

| 写法 | 为什么被拒绝 |
| --- | --- |
| `Q = Layout` | 缺参数，布局动作必须给方案名 |
| `Q = Layout\|Center2` | 没有这个方案 |
| `1 = WinBind\|10` | 槽位只能是单个数字 |
| `G = Guides\|zz` | 参数只能是 `h` / `v` / `x` |
| `X = NotAnAction` | 没有这个动作 |

删除某个键的绑定：把动作选成“（未绑定）”，或者点“清除绑定”按钮，保存后该键就从配置里消失。

## 全局快捷键

另外有一组**全局**快捷键，任何时候按都生效（不用先双击 Alt）：`Alt+反引号` 在同一个程序的窗口之间切换，`Shift+Alt+反引号` 反向切。它由「窗口切换」插件提供，不归等待态管，单独写在一篇：[20 窗口切换](./20-窗口切换.md)。

## 冲突与优先级

- 同一个键写两行，以最后一行准。
- 按键只在等待态生效，也就是双击 Alt 之后的 3 秒内。平时完全不拦截键盘。
- 大小写不影响，`q` 和 `Q` 是同一个键。
