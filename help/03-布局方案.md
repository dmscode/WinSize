布局方案
========

一个布局方案由一个名字和一条规则组成。名字给按键引用，规则决定窗口落在哪、多大。

默认已经配好九个，够用就不用改。

## 规则格式

```
x|y|宽|高
x|y|宽|高|显示器编号
```

前四段用 `|` 分隔，第五段可选。每段都是一个尺寸表达式：

```
[倍率]基准[±偏移]
```

比如 `50sw` 是屏幕工作区宽度的一半，`100sh-40` 是工作区高度减 40 像素。

### 基准单位

| 单位 | 含义 |
| --- | --- |
| `sw` / `sh` | 所选显示器工作区的宽 / 高（工作区是屏幕减去任务栏） |
| `ww` / `wh` | 窗口当前的宽 / 高 |
| `vw` / `vh` | 所有显示器合起来的虚拟屏宽 / 高 |

日常优先用 `sw` 和 `sh`。它们跟着分辨率和任务栏变化，换屏幕不用改配置。

### 偏移

| 写法 | 含义 |
| --- | --- |
| `50sw` | 工作区宽度的一半 |
| `50sw-40` | 一半再减 40 像素 |
| `100sh-120` | 满高减 120 像素，给别的窗口留位置 |
| `800` | 800 像素 |
| `-10` | 负 10 像素，可以落到屏幕外 |
| `50sw+50vw` | 多项相加，用于跨屏 |

数字可以带小数点，比如 `33.3sw`。

### 坐标原点

| 规则里有没有 `vw` / `vh` | 起点 |
| --- | --- |
| 没有 | 所选显示器工作区的左上角 |
| 有 | 虚拟屏的左上角，也就是所有显示器合成的大矩形 |

跨屏写法要用 `vw` / `vh`。一旦切到虚拟屏坐标，`0,0` 就是最左边那块屏的左上角。

### 第五段：放在哪块屏

| 写法 | 结果 |
| --- | --- |
| 不写 | 鼠标所在的那块屏 |
| `\|2` | 第 2 块屏（按系统显示器编号，从 1 开始） |
| `\|0` 或编号越界 | 和不写一样 |

## 九个默认方案

| 名字 | 规则 | 位置 |
| --- | --- | --- |
| `LeftTop` | `0\|0\|50sw\|50sh` | 左上四分之一 |
| `FullTop` | `0\|0\|100sw\|50sh` | 上半屏 |
| `RightTop` | `50sw\|0\|50sw\|50sh` | 右上四分之一 |
| `FullLeft` | `0\|0\|50sw\|100sh` | 左半屏 |
| `Center` | `20sw\|20sh\|60sw\|60sh` | 居中 60%，适合截图 |
| `FullRight` | `50sw\|0\|50sw\|100sh` | 右半屏 |
| `LeftBottom` | `0\|50sh\|50sw\|50sh` | 左下四分之一 |
| `FullBottom` | `0\|50sh\|100sw\|50sh` | 下半屏 |
| `RightBottom` | `50sw\|50sh\|50sw\|50sh` | 右下四分之一 |

它们和按键、鼠标区一一对应：

```
Q W E        1 2 3
A S D   ⇔    4 5 6
Z X C        7 8 9
```

## 怎么改

### 用设置页

托盘 → 设置 → 布局。每条一行，左边名字，右边规则。

- 改名字：直接点名字。引用它的按键和九宫格会跟着改。
- 改规则：在输入框里写，右侧有实时预览。
- 加一条：点底部“＋ 添加一条”。
- 删一条：点行尾删除按钮。被按键引用的方案删不掉，会提示你先改那个键。

保存时会校验。格式不对或宽高小于等于 0，会整批拒绝，并指出是哪一条。

### 让 AI 写规则

记不住单位没关系。设置页的布局区右上角有“提示词给 AI ▾”：

1. 点开，里面有一段提示词，包含语法说明和你当前的屏幕尺寸。
2. 点“复制”。
3. 打开任意网页版 AI，粘贴，末尾补一句需求，比如：

   > 左边 60% 给浏览器，右边上下各放一个编辑器

4. AI 会回一行规则，比如 `0|0|60sw|100sh`。
5. 把这一行粘到对应条目的规则框里，保存。

提示词里已经写了“只输出一行、不要解释、不要代码块”，一般拿回来就能用。如果 AI 用了中文竖线 `｜`，改回英文 `|` 即可。

### 手动改文件

`Config.ini` 的 `[Layout]` 节：

```ini
[Layout]
LeftTop     = 0|0|50sw|50sh
MyWide      = 0|0|70sw|100sh
```

改完在等待态按 `R` 重载，或点托盘菜单的“重载”。详见 [15 配置文件](./15-配置文件.md)。

## 三条容易出错的规则

1. `[Layout]` 是整体覆盖，不是追加。文件里有 `[Layout]` 节，就会完全替换内置的九个方案。想保留默认值，要一起写进去。
2. 名字**不区分大小写**，也不能含 `|`。写 `Center` 和 `center` 会被当成同一个名字（后写的覆盖先写的），按键引用时大小写随意。
3. 宽高必须大于 0。`0|0|0|50sh` 会被拒绝。想要 1 像素宽就写 `1`。

这也是建议用设置页改的原因：它会把完整的表写回去，不容易漏掉默认方案。

## 窗口摆不到目标位置

程序会回读窗口的实际矩形，再和目标比对。

| 情况 | 现象 | 原因 |
| --- | --- | --- |
| 差 1~2 像素 | 没有提示 | 系统取整、边框补偿 |
| 尺寸停住不再变 | 窗口比目标大或小，没有提示 | 应用自己有最小尺寸限制，见 [17](./17-常见问题.md) |
| 位置完全没变 | 提示 `TARGET NEEDS ADMIN` | 目标窗口以管理员运行 |

第二种最常见，不是程序的问题。很多 Electron 应用的最小尺寸在 800×600 以上，让它变成 1280×720 可以，变成 1280×500 就只能停在 600。
