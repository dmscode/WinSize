布局方案
========

一个布局方案 = **一个名字** + **一条规则**。名字给按键引用，规则决定窗口落在哪、多大。

默认给好了九个，够用就不必改。

## 规则长什么样

```
x|y|宽|高
x|y|宽|高|显示器编号
```

四段用 `|` 分隔，第五段可选。每段都是一个"尺寸表达式"：

```
[倍率]基准[±偏移]
```

例如 `50sw` 表示"屏幕工作区宽度的一半"，`100sh-40` 表示"工作区高度减 40 像素"。

### 基准单位

| 单位 | 含义 |
| --- | --- |
| `sw` / `sh` | **所选显示器工作区**的宽 / 高（工作区 = 屏幕减去任务栏） |
| `ww` / `wh` | 窗口**当前**的宽 / 高 |
| `vw` / `vh` | **全部显示器合起来的虚拟屏**宽 / 高 |

`sw`、`sh` 是日常最该用的：它跟着分辨率和任务栏变化，换屏幕不用改配置。

### 偏移

| 写法 | 含义 |
| --- | --- |
| `50sw` | 工作区一半 |
| `50sw-40` | 一半再减 40 像素 |
| `100sh-120` | 满高减 120 像素（给别的窗口留位置） |
| `800` | 纯像素：800 |
| `-10` | 纯像素：负 10（可以落在屏幕外） |
| `50sw+50vw` | 多项叠加，用于跨屏 |

数字可以带小数点（`33.3sw`）。

### 坐标原点

| 规则里有没有 `vw` / `vh` | 起点 |
| --- | --- |
| 没有 | **所选显示器工作区的左上角** |
| 有 | **虚拟屏的左上角**（所有显示器合成的那个大矩形） |

这就是跨屏写法必须用 `vw`/`vh` 的原因：一旦换成虚拟屏坐标，`0,0` 就是最左边那块屏的左上角。

### 第五段：钉在哪块屏

| 写法 | 落在 |
| --- | --- |
| 不写 | 鼠标所在的那块屏 |
| `\|2` | 第 2 块屏（按系统的显示器编号，从 1 开始） |
| `\|0` 或编号越界 | 同"不写" |

## 九个默认方案

| 名字 | 规则 | 位置 |
| --- | --- | --- |
| `LeftTop` | `0\|0\|50sw\|50sh` | 左上四分之一 |
| `FullTop` | `0\|0\|100sw\|50sh` | 上半屏 |
| `RightTop` | `50sw\|0\|50sw\|50sh` | 右上四分之一 |
| `FullLeft` | `0\|0\|50sw\|100sh` | 左半屏 |
| `Center` | `20sw\|20sh\|60sw\|60sh` | 居中 60%，适合截图 |
| `FullRight` | `50sw\|0\|50sw\|100sh` | 右半屏 |
| `LeftBottom` | `0\|50sh\|50sw\|50sh` | 左下四分之一 |
| `FullBottom` | `0\|50sh\|100sw\|50sh` | 下半屏 |
| `RightBottom` | `50sw\|50sh\|50sw\|50sh` | 右下四分之一 |

它们与按键、鼠标区**一一对应**：

```
Q W E        1 2 3
A S D   ⇔    4 5 6
Z X C        7 8 9
```

## 怎么改

### 图形化（推荐）

托盘 → 设置 → **布局**。每条一行：左边名字、右边规则。

- 改名字：直接点名字改。指向它的按键与九宫格会自动跟着改。
- 改规则：直接在输入框里写，右侧有实时预览。
- 加一条：底部「＋ 添加一条」。
- 删一条：行尾的删除按钮。**被按键引用的方案删不掉**，会提示你先改那个键。

保存时会校验：格式不对、宽高 ≤ 0 都会被整批拒绝，并指出是哪一条。

### 让 AI 写规则

记不住单位没关系。设置页的「布局」区右上角有 **「提示词给 AI ▾」**：

1. 点开，里面是一整段提示词，含**语法说明**和**你当前的屏幕尺寸**。
2. 点「复制」。
3. 打开任意网页版 AI，粘贴，末尾补一句你的需求，例如：

   > 左边 60% 给浏览器，右边上下各放一个编辑器

4. 它会回一行规则，例如 `0|0|60sw|100sh`。
5. 复制这一行，粘到对应条目的规则框里，保存。

提示词里已经写明"只输出一行、不要解释、不要代码块"，所以拿回来基本可以直接用。
如果 AI 返回的格式跑偏（比如用了中文竖线 `｜`），改回英文 `|` 即可。

### 手动改文件

`Config.ini` 的 `[Layout]` 节：

```ini
[Layout]
LeftTop     = 0|0|50sw|50sh
MyWide      = 0|0|70sw|100sh
```

改完在等待态按 `R` 重载，或在托盘菜单点「重载」。详见 [15 配置文件](./15-配置文件.md)。

## 三条容易踩的规则

**1. `[Layout]` 是整体覆盖，不是追加。**
文件里有 `[Layout]` 节，就**完全替换**内置的九个默认方案。想保留默认值，就要把它们一起写进去。
（这也是为什么建议用设置页改——它会帮你把完整的表写回去。）

**2. 名字区分大小写，且不能含 `|`。**
`Center` 和 `center` 是两个不同的名字。按键里引用时必须完全一致。

**3. 宽高必须大于 0。**
`0|0|0|50sh` 会被拒绝。想要"只有一个像素宽"就写 `1`。

## 窗口摆不到目标位置

程序会回读窗口的实际矩形，与目标比对。结果分几种：

| 情况 | 现象 | 原因 |
| --- | --- | --- |
| 差 1~2 像素 | 无提示，正常 | 系统取整、边框补偿 |
| 尺寸停住不再变 | 无提示，窗口比目标大或小 | **应用自己有最小尺寸限制**（详见 [17](./17-常见问题.md)） |
| 位置完全没变 | 提示 `TARGET NEEDS ADMIN` | 目标窗口以管理员运行 |

第二种最常见，不是程序的问题：很多 Electron 应用有 800×600 以上的最小尺寸，
你让它变成 1280×720 它接受，让它变成 1280×500 它就只能停在 600。
