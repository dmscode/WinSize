窗口置顶
========

把当前窗口钉在所有窗口前面，或者取消它原来的置顶。

## 怎么用

双击左 Alt → 按 `P`。提示 `Pinned` 是已置顶，`Unpin` 是已取消。

就是这个开关，没有别的。

## 什么时候有用

| 场景 | 用法 |
| --- | --- |
| 边写文档边看参考窗口 | 把参考窗口钉住，它就不会被盖住 |
| 某个程序的弹窗老是挡着 | 一般不能取消——但有些程序允许，按 `P` 试一下 |
| 看视频/教程时做别的 | 钉住视频窗口 |
| 钉住后还想摆在角落 | 钉住不影响布局，接着按 `Q`/`C` 摆到四分之一屏 |

## 多个置顶窗口怎么排

多个置顶窗口之间**互不特殊**：谁在前台谁在最前，跟你切换的顺序一致。

换句话说，置顶不是"最上层且永不遮挡"，而是"永远在所有普通窗口之上"。
置顶窗口彼此之间仍然是普通的层叠关系。

## 注意

- 置顶状态**不写入配置**，也不跟着窗口绑定走。窗口关掉就没了。
- 置顶是窗口自己的属性，有些程序会自己重置它（比如某些播放器全屏后会取消置顶）。
- 把窗口钉住之后再摆布局，位置照常生效；但如果目标位置被别的置顶窗口占了，遮住就遮住了。
