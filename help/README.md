WinSize 帮助
============

WinSize 只做一件事：把当前窗口快速摆到你想要的位置。

平时只用三个动作：双击左 Alt，按一个键，窗口就位。九宫格手势、窗口书签、辅助线、设置页，都是围绕这个流程的补充。

## 三十秒上手

1. 运行 `WinSize.exe`。托盘会出现图标，没有主窗口，这是正常的。
2. 在半秒内按两下左 Alt，屏幕底部会出现 `WAITING`。
3. 按 `A`，当前窗口贴到左半屏；按 `D`，贴到右半屏。

`Q W E / A S D / Z X C` 和九宫格的位置对应：

```
Q W E         左上  顶部  右上
A S D    ⇔    左侧  居中  右侧
Z X C         左下  底部  右下
```

## 运行环境

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 11 x64（只在这个环境完整验证过；Windows 10 没实测） |
| 运行时 | 不需要安装 AutoHotkey，`WinSize.exe` 自带 |
| 权限 | 普通用户即可，不需要管理员 |

程序是绿色版：除开机自启外不写注册表，不安装服务，删掉文件夹就算卸载。

先用默认配置几天。哪个键不顺手再改，不需要一开始就把设置页翻一遍。
