WinSize 帮助
============

WinSize 只有一个作用：**把当前窗口快速摆到你要的位置**。

日常用到的操作只有三个动作：双击左 Alt、按一个键、窗口就位。其余都是这条主线的补充——
九宫格鼠标手势、窗口书签、辅助线、以及把一切都调到顺手的设置页。

## 三十秒上手

1. 运行 `WinSize.exe`，托盘出现图标，**没有主窗口**，这是正常的。
2. 双击**左 Alt**（半秒内按两下），屏幕底部出现一条 `WAITING`。
3. 按 `A`，当前窗口贴到左半屏；按 `D`，贴到右半屏。

`Q W E / A S D / Z X C` 与九宫格同形，位置即结果：

```
Q W E         左上  顶部  右上
A S D    ⇔    左侧  居中  右侧
Z X C         左下  底部  右下
```

## 运行环境

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 11 x64（仅在此环境完整验证过；Windows 10 未实测） |
| 运行时 | 不需要安装 AutoHotkey，`WinSize.exe` 自带 |
| 权限 | 普通用户即可；不需要管理员 |

程序是**绿色版**：不写注册表（开机自启除外）、不装服务，删掉文件夹就是卸载。

## 一句话原则

> 能省的都省了。默认配置开箱即用——九个方案、九个按键、九个鼠标区一一对应，
> 尺寸全部按屏幕百分比计算，换分辨率、加显示器都不用改配置。

先按默认用几天，觉得哪个键不顺手再改。**不需要一上手就把设置页翻一遍。**
