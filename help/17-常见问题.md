常见问题
========

按现象整理。遇到问题先看 `Debug.log`，托盘菜单的“打开日志”可以直接打开。

## 双击 Alt 没反应

按顺序检查：

| 检查 | 怎么看 |
| --- | --- |
| 程序在跑吗 | 托盘有没有图标，可能在 `^` 溢出区里 |
| 被杀软拦了吗 | 火绒等会按路径拦截，把整个文件夹加入白名单 |
| 是不是开了两个实例 | 只有一个能生效。任务管理器里看 `WinSize.exe` 是否多于一个 |
| 双击够快吗 | 两次间隔不超过 0.5 秒，在第二次松开时判定 |
| 是不是按了右 Alt | 只有左 Alt 有效 |

托盘图标在、也没被杀软拦，就看双击 Alt 时屏幕上有没有出现提示条（青蓝或橙色）。**双击本身不写日志**，别用“日志里没有记录”来判断它坏了；日志里有 `启动 x.y.z` 只说明程序起来了。完全没有提示条，多半是 Alt 被别的程序独占，或者键盘钩子被安全软件拦了。

## 提示条是橙色

这是命令模式，不是错误。前台没有可操作的窗口，可能是桌面、任务栏，或者窗口在排除表里。

用鼠标点一下目标窗口，再双击 Alt，就会恢复青蓝。详见 [02 基本用法](./02-基本用法.md)。

## 窗口摆不到目标位置

三种情况：

| 现象 | 原因 | 怎么办 |
| --- | --- | --- |
| 位置和尺寸差 1~2 像素 | 系统取整、边框补偿 | 正常，不用管 |
| 尺寸停住不再变，窗口比目标大 | 应用自己有最小尺寸限制 | 换大一点的目标。这是应用的限制，不是程序的问题 |
| 位置完全没变，提示 `TARGET NEEDS ADMIN` | 目标窗口以管理员身份运行 | 见下一条 |

第二种很常见。不少 Electron 应用最小宽度在 1000 以上，让它变成 800 宽，它只能停在 1000。用鼠标拖框时也一样，拖到比最小尺寸还小，窗口不会继续缩小。

## 提示 TARGET NEEDS ADMIN

系统不允许普通权限进程操作管理员权限窗口，这是 UIPI 限制。

三种选择：

1. 接受它。大多数时候并不需要摆那个窗口。
2. 让那个程序以普通权限运行。多数程序不需要管理员。
3. 以管理员身份运行 WinSize。但这会让它摆不动普通窗口，等于把问题换了个方向。

不建议第 3 种，除非你要摆的窗口全是管理员窗口。

## 按键提示 No Action.

这个键没绑定动作。常见原因：

| 原因 | 怎么办 |
| --- | --- |
| 改过 `[Keys]`，把其它键覆盖掉了 | `[Keys]` 是整体覆盖，改一个键也要写全 |
| 插件被关了，动作消失 | 在设置页把插件勾回来 |
| 键名写错，比如 `-` 写成别的符号 | 看日志里的“按键绑定无法注册” |

## 按键提示 Error Action

动作名写错，或者缺少参数。日志里会写清是哪个键、什么动作、什么原因。

常见的是 `Layout` 后面忘了写方案名。`Q = Layout` 应该是 `Q = Layout|LeftTop`。

## 设置页打不开

| 现象 | 处理 |
| --- | --- |
| 浏览器显示无法连接 | 程序没在跑，或者端口被占，看 `Debug.log`；从托盘再点一次“设置” |
| 页面空白或 404 | 程序目录缺 `web` 文件夹，重新解压发布包 |
| 提示目录不可写 | 程序放在没有写权限的位置，比如 `C:\Program Files`，换到用户目录 |
| 点设置没反应，提示 `Settings Error` | 端口被占或目录不可写，看日志 |

## 开机没有自启

| 检查 | 说明 |
| --- | --- |
| 设置页的勾选框还在吗 | 有些系统优化工具会清启动项，勾一下再看 |
| 任务管理器 → 启动 | 里面有个 WinSize，可能被禁用了 |
| 杀软拦了启动项 | 加白名单 |

程序写的是 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 下的 `WinSize`，不需要管理员权限。

## 输入法老是断

多半开了悬停激活。鼠标停在哪，0.8 秒后就把那个窗口切到前面，输入法组合被切断。

程序已经加了“最近 1 秒有键盘输入就不激活”的保护。但如果你打得慢，或者停手超过 1 秒，仍会被切。按 `T` 暂停，或者在设置页把插件关掉。

## 大写键变得怪

开了大写提示插件后，程序接管了 CapsLock，为了让提示始终准确。如果你有别的软件也用 CapsLock，比如改键工具、游戏宏，两者会打架。

关掉大写提示插件即可，CapsLock 会恢复系统原生行为。见 [12 大写提示](./12-大写提示.md)。

## LAlt + 右键没反应

三种可能：

1. 快速布局被关了。设置页 → 常规 → 快速布局。这个开关是整套手势的总闸，关掉后九宫格和拖框都不响应。
2. 拖拽调整插件被关了。设置页 → 插件 → 拖拽调整。
3. 点在被排除的窗口上。排除的窗口不响应任何手势。

## 排除规则突然不生效

多半是文件编码被改了。`Config.ini` 需要 UTF-8 带 BOM，存成 ANSI 会让中文路径变乱码，规则就匹配不上。

用记事本“另存为”时选 UTF-8，不要选 ANSI。或者直接用设置页改。

## 想恢复出厂设置

1. 托盘 → 退出。
2. 把 `Config.ini` 改名或删掉。
3. 重新启动。

程序会用内置默认值启动，九个方案、九个按键、九个鼠标区照常能用。**注意文件不会自动重建**：这时打开设置页保存会失败（提示找不到配置文件）。所以更稳的做法是先把 `Config.ini` 改名留底，确认要重置再从发布包里拷一份新的 `Config.ini` 过来。窗口绑定记录也在这个文件里，会被一起清掉。

## 日志在哪

`WinSize.exe` 同目录的 `Debug.log`。

| 开关 | 记什么 |
| --- | --- |
| `[Switch] logError = 1`，默认 | 启动信息，加上全部警告与错误（按键绑定失败、执行失败、配置重载失败） |
| `logError = 0` | 只记错误与致命错误 |

日志是追加写的。超过 1 MB 会自动轮转：当前文件转成 `Debug.log.1`，旧的往后挪，最多留三份（`Debug.log.1`~`.3`），总占用约 4 MB，不用手动清理。想清空可以直接删掉，程序下次启动会重建。

## 还是没有答案

在日志里搜这几个关键词，通常能定位：

| 关键词 | 看什么 |
| --- | --- |
| `按键绑定无效` / `按键绑定无法注册` | 前者是动作名写错或参数缺失，后者是键名非法或被占用 |
| `Bad Layout` / `布局` | 哪个方案的规则写坏了 |
| `blocked` / `limited` | 窗口摆不动的原因（前者是被拒绝，后者是被尺寸约束） |
| `插件` | 插件启用或禁用失败 |
