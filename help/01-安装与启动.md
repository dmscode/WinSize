安装与启动
==========

WinSize 是绿色版程序：解压即用，删除即卸载。

## 系统要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 11 x64（仅在此环境完整验证过，Windows 10 未实测） |
| 运行时 | 无需安装 AutoHotkey，exe 自带 |
| 权限 | 普通用户即可，**不要**用管理员运行（见文末） |

## 装在哪

解压到一个**自己有写权限**的目录，例如：

```
D:\Apps\WinSize\
├─ WinSize.exe      主程序
├─ Config.ini       配置（首次运行若不存在，程序会用内置默认值）
├─ Readme.md        发布说明
└─ web\             设置页
```

不要把程序放进 `C:\Program Files\` 之类的目录——程序会把 `Config.ini`、`Debug.log`、
`runtime.json` 写在 **exe 旁边**，没有写权限时配置存不下来，设置页会报"目录不可写"。

## 第一次运行

双击 `WinSize.exe`。**会看到的现象**：托盘多一个图标，然后什么都没有。

这是正常的：程序没有主界面，所有操作都从"双击左 Alt"和"右键托盘图标"开始。

如果托盘图标没出现，检查是不是被折叠进了托盘溢出区（任务栏右下角的 `^`）。

## 开机自启

托盘右键 → 设置 → 常规 → 勾选**开机自启**，立即生效。

它写的是当前用户的注册表启动项（`HKCU\...\Run`），不需要管理员权限，也只影响你自己这个账户。
取消勾选就是删除该项。

> 程序会在启动 60 秒后查一次新版本，之后每 24 小时一次。它只读取一个记录版本号的
> 几十字节文件，不下载安装包、不上传任何信息；不想要就在设置里关掉「自动检查更新」，
> 关掉之后完全不联网。要不要开机自启完全由你决定。

## 杀毒软件拦截

WinSize 是 AutoHotkey 编译的程序，且会注册键盘钩子，**部分杀软会误报或静默拦截**。
实测火绒会按路径拦截陌生 exe，表现为「程序启动了但按键没反应」。

遇到这种情况，把 WinSize 所在**文件夹**加入杀软白名单（信任区），而不是只加 exe 文件——
程序会在同目录写 `Config.ini` 与 `Debug.log`，只信任 exe 仍可能被拦住写文件。

## 只能开一个

程序是单实例的。重复双击 exe 时，第二个实例会弹一句"WinSize 已经在运行"然后自己退出。

这是刻意的：两个实例会互相抢同一个热键（后注册的优先），表现是"双击 Alt 偶尔没反应"，
非常难查。

## 退出与重启

| 操作 | 入口 |
| --- | --- |
| 退出 | 托盘右键 → 退出 |
| 重启 | 托盘右键 → 重启；或等待态按 `B` |
| 重读配置 | 托盘右键 → 重载；或等待态按 `R` |

「重载」只重读 `Config.ini`，不重启进程；「重启」会重新启动程序本身。

> 托盘菜单里的「设置」与「退出」**删不掉**。少了这两个，就只能去任务管理器结束进程了。

## 升级

1. 退出旧版（托盘 → 退出）。
2. 用新 exe 覆盖旧 exe。
3. **保留原来的 `Config.ini`**，配置格式向下兼容，新增的开关会自动补进去。

想从零开始就把 `Config.ini` 删掉，程序会按内置默认值重建一份。

## 卸载

托盘 → 退出，然后删除整个文件夹。如果开过机自启，先去设置页取消勾选。
没有残留的服务、驱动或注册表项。

## 不要用管理员运行

用管理员运行时，普通权限的窗口会摆不动（系统不允许低权限进程操作高权限窗口，反之亦然）。
只有当你需要调整的目标窗口本身就是管理员窗口时，才考虑用管理员运行 WinSize，
而且托盘会同时存在两个不同权限的实例，容易混淆。

默认用普通权限，遇到个别窗口摆不到目标位置，多半是它自己的最小尺寸限制，不是权限问题。
