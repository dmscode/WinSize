安装与启动
==========

WinSize 是绿色版程序：解压就能用，删掉文件夹就卸载。

## 系统要求

| 项 | 要求 |
| --- | --- |
| 系统 | Windows 11 x64（只在这个环境完整验证过，Windows 10 没实测） |
| 运行时 | 不需要安装 AutoHotkey，exe 自带 |
| 权限 | 普通用户即可，不要用管理员运行（原因见文末） |

## 装在哪

解压到一个你有写权限的目录，例如：

```
D:\Apps\WinSize\
├─ WinSize.exe      主程序
├─ Config.ini       配置（首次运行不存在时，程序使用内置默认值）
├─ Readme.md        发布说明
└─ web\             设置页
```

不要放进 `C:\Program Files\` 这类目录。程序会把 `Config.ini`、`Debug.log`、`runtime.json` 写在 exe 旁边，没有写权限时配置存不下来，设置页会提示“目录不可写”。

## 第一次运行

双击 `WinSize.exe`。托盘会多一个图标，然后没有别的窗口，这是正常的。程序没有主界面，所有操作都从双击左 Alt 或右键托盘图标开始。

如果托盘图标没出现，先看看是不是被折叠进了任务栏右下角的 `^` 溢出区。

## 开机自启

托盘右键 → 设置 → 常规 → 勾选“开机自启”，立即生效。

它写入当前用户的注册表启动项（`HKCU\...\Run`），不需要管理员权限，只影响你这个账户。取消勾选就会删除该项。

打开设置页时会读取一次版本号。有新版本时，设置页和托盘会提示。它只读取一个记录版本号的几十字节文件，不下载安装包，也不上传信息。不想要就在设置里关掉“打开设置页时检查更新”；程序不会在后台定时联网。

要不要开机自启，完全由你决定。

## 杀毒软件拦截

WinSize 由 AutoHotkey 编译，会注册键盘钩子，部分杀软可能误报或静默拦截。实测火绒会按路径拦截陌生 exe，表现是“程序启动了，但按键没反应”。

遇到这种情况，把 WinSize 所在的文件夹加入杀软白名单，不要只加 exe 文件。程序会在同目录写 `Config.ini` 和 `Debug.log`，只信任 exe 仍可能被拦住写文件。

## 只能开一个

程序是单实例的。重复双击 exe 时，第二个实例会提示“WinSize 已经在运行”，然后自行退出。

这是有意设计的。两个实例会抢同一个热键，后注册的优先，表现是“双击 Alt 偶尔没反应”，很难排查。

## 退出与重启

| 操作 | 入口 |
| --- | --- |
| 退出 | 托盘右键 → 退出 |
| 重启 | 托盘右键 → 重启；或等待态按 `B` |
| 重读配置 | 托盘右键 → 重载；或等待态按 `R` |

“重载”只重读 `Config.ini`，不重启进程。“重启”会重新启动程序本身。

托盘菜单里的“设置”和“退出”删不掉。少了这两个入口，就只能去任务管理器结束进程。

## 升级

1. 退出旧版：托盘 → 退出。
2. 用新 exe 覆盖旧 exe。
3. 保留原来的 `Config.ini`。配置格式向下兼容，新增的开关会自动补进去。

想从零开始，先把 `Config.ini` 改名留底，再从发布包里拷一份新的 `Config.ini` 过来。**直接删掉不行**：程序会用内置默认值运行，但文件不会自己重建，之后设置页保存会失败。

## 卸载

托盘 → 退出，然后删除整个文件夹。如果开过机自启，先去设置页取消勾选。

没有残留的服务、驱动或注册表项。

## 不要用管理员运行

用管理员运行 WinSize 时，普通权限的窗口会摆不动，因为系统不允许低权限进程操作高权限窗口。只有目标窗口本身就是管理员窗口时，才考虑用管理员运行 WinSize——但先把普通权限那个**退出**：程序是单实例的，第二个只会提示"已经在运行"然后退出，不会两个同时跑。

默认用普通权限。遇到个别窗口摆不到目标位置，多半是窗口自己的最小尺寸限制，不是权限问题。

程序能做什么、每个键是什么，见 [02 基本用法](./02-基本用法.md)。
