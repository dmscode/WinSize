基本用法
========

全程序只有一个交互模型：**双击左 Alt → 屏幕底部出现提示条 → 按一个键**。

## 完整流程

1. 你正在用某个窗口（浏览器、编辑器……）。
2. 半秒内按两下**左边的 Alt**。
3. 屏幕底部（鼠标所在那块屏）出现一条窄提示条，写着 `WAITING`。
4. 按一个键，比如 `A`。
5. 提示条消失，目标窗口贴到左半屏。

提示条不需要点、不会抢焦点，也不会挡住你要看的东西——它只在等待你的那一下按键。

## 双击是怎么判定的

| 条件 | 值 |
| --- | --- |
| 按哪个键 | 左侧 Alt（右 Alt 无效） |
| 两次间隔 | ≤ 500 毫秒 |
| 判定时机 | 第二次**松开**时 |
| 已经在等待态时 | 不会再触发一次 |

单手食指双击 Alt 是最省力的手势，所以默认就是它。这个键不能改。

## 提示条

| 项 | 说明 |
| --- | --- |
| 位置 | 鼠标所在显示器的**工作区底部居中** |
| 宽度 | 固定，不会因为文字长短跳动 |
| 时长 | 3 秒自动消失 |
| 提前消失 | 目标窗口不再是前台（你切走了） |
| 显示内容 | 默认 `WAITING`；开了"等待界面显示时间"则显示如 `11-14 10:30` |

想让它显示时间：设置页 → 常规 → **等待界面显示时间**。
不显示秒、不显示年——它是给你确认"现在几点"的，不是时钟。

## 两种颜色：这是最重要的一条

提示条底部有一条色边，颜色说明**当前是什么状态**：

| 颜色 | 文案 | 含义 | 能做什么 |
| --- | --- | --- | --- |
| **青蓝** | `WAITING` | 有一个可操作的目标窗口 | 全部按键 |
| **橙色** | `NO WINDOW` | 没有可操作的目标窗口 | 只能执行不需要窗口的键（重载、帮助、设置、辅助线、窗口绑定……） |

橙色不是出错，是**命令模式**：你现在停在桌面、或者前台窗口被排除了，
所以「把窗口摆到左半屏」这类动作没有意义。此时按布局键会提示 `No Window Available`。

用鼠标点一下别的窗口再双击 Alt，就会回到青蓝。

## 目标窗口是谁

**双击 Alt 那一刻处于激活状态的窗口**，不是鼠标下面的窗口。

程序会做过滤，以下情况会进入橙色的命令模式：

- 前台是桌面、任务栏、开始菜单；
- 该窗口规则命中了你的**排除列表**（见 [07 窗口排除](./07-窗口排除.md)）；
- 前台窗口是程序自己的提示条。

## 默认按键全表

九宫格同形的九个布局键，是第一组要记住的：

```
Q W E      左上  顶部  右上
A S D  ⇔   左侧  居中  右侧
Z X C      左下  底部  右下
```

其余按键按用途分组：

| 键 | 作用 | 详见 |
| --- | --- | --- |
| `P` | 窗口置顶 / 取消置顶 | [08](./08-窗口置顶.md) |
| `U` | 排除当前窗口 / 取消排除 | [07](./07-窗口排除.md) |
| `1`~`9`、`0` | 窗口绑定：绑定 / 唤回 / 解绑该槽位 | [09](./09-窗口绑定.md) |
| `G` | 辅助线开关 | [10](./10-辅助线.md) |
| `-` | 只要横向辅助线 | [10](./10-辅助线.md) |
| `=` | 十字辅助线 | [10](./10-辅助线.md) |
| `\` | 只要纵向辅助线 | [10](./10-辅助线.md) |
| `T` | 悬停激活：开始 / 暂停 | [11](./11-悬停激活.md) |
| `R` | 重读 `Config.ini` | [15](./15-配置文件.md) |
| `H` | 打开本帮助 | [13](./13-托盘菜单.md) |

## 提示条上的文字是什么意思

程序只用几句话回应你，都很短：

| 文字 | 意思 | 该怎么办 |
| --- | --- | --- |
| `No Action.` | 这个键没绑定任何动作 | 去设置页的「按键」区看看 |
| `No Window Available` | 命令模式下按了需要窗口的键 | 先点一下目标窗口 |
| `Error Action` | 动作名写错、或缺少参数 | 看 `Debug.log`，里面有具体键名 |
| `Bad Layout` | 布局规则有写坏的，重载时被拦下 | 日志里会列出是哪个方案 |
| `Excluded.` | 已把这个窗口加入排除 | — |
| `Unexcluded.` | 已取消排除 | — |
| `Pinned` / `Unpin` | 已置顶 / 已取消置顶 | — |
| `Bind 3` / `Unbind 3` | 已绑定 / 已解绑 3 号槽位 | [09](./09-窗口绑定.md) |
| `SLOT CLEARED` | 该槽位记录的窗口已经不在了，槽位已清空 | 重新绑定一次 |
| `TARGET NEEDS ADMIN` | 目标窗口以管理员运行，摆不动 | 见 [17 常见问题](./17-常见问题.md) |

## 一个建议

刚开始只记 `Q W E / A S D / Z X C` 九个键，其余用到再查。
按键太多会记混，而九宫格是唯一值得肌肉记忆的一组。
