基本用法
========

整个程序只有一个操作流程：双击左 Alt，屏幕底部出现提示条，按一个键。

## 完整流程

1. 你正在使用某个窗口，比如浏览器或编辑器。
2. 在半秒内按两下左边的 Alt。
3. 鼠标所在屏幕的底部会出现一条窄提示条。默认显示当前时间（如 `11-14 10:30`），关掉“等待界面显示时间”后显示 `WAITING`。
4. 按一个键，比如 `A`。
5. 提示条消失，目标窗口贴到左半屏。

提示条不需要点击，不会抢焦点，也不会挡住你要看的内容。它只等你按下一个键。

同一次双击还会在窗口之间的边界上放出橙色把手：按住拖动可以同时改两侧窗口的尺寸，用不上就按 `Esc` 退出等待态。详见 [19 边界控制点](./19-边界控制点.md)。

## 双击的判定

| 条件 | 值 |
| --- | --- |
| 按哪个键 | 左侧 Alt（右 Alt 无效） |
| 两次间隔 | 不超过 500 毫秒 |
| 判定时机 | 第二次松开时 |
| 已经在等待态 | 不会再次触发 |

单手食指双击左 Alt 最省力，所以默认用它。这个键不能改。

## 提示条

| 项 | 说明 |
| --- | --- |
| 位置 | 鼠标所在显示器的工作区底部居中 |
| 宽度 | 固定，不随文字长短变化 |
| 时长 | 3 秒后自动消失 |
| 提前消失 | 目标窗口不再是前台窗口 |
| 显示内容 | 默认是 `11-14 10:30` 这样的时间；关掉“等待界面显示时间”后显示 `WAITING`（无窗口时 `NO WINDOW`） |

不想看时间：设置页 → 常规 → 等待界面显示时间，取消勾选即可。

时间不显示秒和年份，只用来确认当前时间，不是时钟。

## 两种颜色

提示条底部有一条色边，颜色表示当前状态。

| 颜色 | 文案 | 含义 | 能做什么 |
| --- | --- | --- | --- |
| 青蓝 | 时间，或 `WAITING` | 有可操作的目标窗口 | 全部按键 |
| 橙色 | 时间，或 `NO WINDOW` | 没有可操作的目标窗口 | 只能执行不需要窗口的键，比如重载、帮助、设置、辅助线、窗口绑定 |

开了“等待界面显示时间”时，两种模式显示的都是时间，只能靠色边区分。

<img src="https://dmscode.github.io/WinSize/images/04-等待条.png" alt="青蓝色边表示有目标窗口，橙色边表示命令模式" width="440">

橙色表示命令模式，不是出错。你可能停在桌面，或者前台窗口被排除了，这时“把窗口摆到左半屏”没有意义。按布局键会提示 `No Window Available`。

用鼠标点一下别的窗口，再双击 Alt，就会回到青蓝状态。

## 目标窗口是谁

目标窗口是双击 Alt 那一刻处于激活状态的窗口，不是鼠标下面的窗口。

以下情况会进入橙色的命令模式：

- 前台是桌面、任务栏或开始菜单。
- 窗口命中了你的排除列表，见 [07 窗口排除](./07-窗口排除.md)。
- 前台是程序自己的提示条。

## 默认按键

九个布局键和九宫格同形：

```
Q W E      左上  顶部  右上
A S D  ⇔   左侧  居中  右侧
Z X C      左下  底部  右下
```

其余按键按用途分组：

| 键 | 作用 | 详见 |
| --- | --- | --- |
| `P` | 窗口置顶 / 取消置顶 | [08](./08-窗口置顶.md) |
| `U` | 排除当前窗口 / 取消排除 | [07](./07-窗口排除.md) |
| `1`~`9`、`0` | 窗口绑定：绑定、唤回、解绑该槽位 | [09](./09-窗口绑定.md) |
| `G` | 辅助线开关 | [10](./10-辅助线.md) |
| `-` | 只开横向辅助线 | [10](./10-辅助线.md) |
| `=` | 十字辅助线 | [10](./10-辅助线.md) |
| `\` | 只开纵向辅助线 | [10](./10-辅助线.md) |
| `T` | 悬停激活：开始 / 暂停 | [11](./11-悬停激活.md) |
| `R` | 重读 `Config.ini` | [15](./15-配置文件.md) |
| `H` | 打开帮助 | [13](./13-托盘菜单.md) |
| `V` | 显示版本号 | — |
| `B` | 重启程序 | [01](./01-安装与启动.md) |

这些键都可以改。改键、加键、删键见 [05 按键绑定](./05-按键绑定.md)。

## 提示文字的意思

程序只会用很短的文字回应你。

| 文字 | 意思 | 怎么办 |
| --- | --- | --- |
| `No Action.` | 这个键没有绑定动作 | 去设置页的“按键”区看看 |
| `No Window Available` | 命令模式下按了需要窗口的键 | 先点一下目标窗口 |
| `Error Action` | 动作名写错，或者缺少参数 | 看 `Debug.log`，里面会写具体键名 |
| `Bad Layout` | 重载时发现布局规则写坏了 | 日志里会列出是哪个方案、原值是什么 |
| `Excluded.` | 已把当前窗口加入排除 | — |
| `Unexcluded.` | 已取消排除 | — |
| `Pinned` / `Unpin` | 已置顶 / 已取消置顶 | — |
| `Bind 3` / `Unbind 3` | 已绑定 / 已解绑 3 号槽位 | [09](./09-窗口绑定.md) |
| `SLOT CLEARED` | 槽位记录的窗口已经不存在，槽位已清空 | 重新绑定 |
| `TARGET NEEDS ADMIN` | 目标窗口以管理员运行，摆不动 | 见 [17 常见问题](./17-常见问题.md) |

刚开始只记 `Q W E / A S D / Z X C` 九个键，其他用到再查。按键多了容易混，九宫格是最值得练熟的一组。
