窗口排除
========

有些窗口你不希望 WinSize 碰它：任务栏、某个全屏播放器、某个总是特殊布局的工具。
把它们排除掉，程序就不会再去摆它、也不会把它绑成书签。

## 用按键排除（最快）

1. 切到那个窗口，让它当前台。
2. 双击左 Alt，按 `U`。

提示 `Excluded.` 就说明加进去了。

**同一个窗口再按一次 `U` 会取消排除**（提示 `Unexcluded.`）。这是幂等的，不用去配置文件里删。

> 想让 `U` 别那么容易被误按，可以把这个键解绑——去设置页的「按键」区把它清空即可。

## 规则的写法

被排除的规则存在 `Config.ini` 的 `[Exclusions]` 节：

```ini
[Exclusions]
1 = D:\Program Files\Microsoft VS Code\Code.exe|Chrome_WidgetWin_1
```

每一行是 `进程|窗口类`：

| 段 | 含义 | 能不能省 |
| --- | --- | --- |
| 进程 | exe 的完整路径，或只写文件名 | 能（留空 = 按类匹配所有进程） |
| 窗口类 | 窗口的类名（Windows 内部标识） | 能（留空 = 该进程的所有窗口） |

前面的编号只是排序用，程序下次写入时会自动重排。

## 在设置页里改

托盘 → 设置 → **窗口排除**。每条一行，两个输入框对应上面的两段；底部「＋ 添加一条」。

比手改文件好在两点：写错了会当场提示，保存后立即生效。

## 内置排除

以下几种窗口是**硬编码排除**的，加不进用户列表，也删不掉：

| 窗口 | 为什么 |
| --- | --- |
| 桌面（`Progman` / `WorkerW`） | 摆桌面没有意义 |
| 任务栏（`Shell_TrayWnd` 等） | 摆任务栏会让整个桌面错乱 |
| 托盘溢出面板 | 同上 |
| 开始菜单、小部件 | 系统 UI，一摆就出问题 |

按 `U` 停在这些窗口上会提示 `No Window`，什么都不会发生。

## 排除之后会怎样

被排除的窗口：

| 影响 | 表现 |
| --- | --- |
| 不能作为布局目标 | 它是前台时双击 Alt，提示条变**橙色**（命令模式） |
| 不能绑定 | 按槽位键连它时会提示 `No Window` |
| 不参与悬停激活 | 鼠标停在上面不会切过去 |

鼠标手势（`LAlt + 右键`）也同理：点在被排除的窗口上不会有反应。

## 一个典型用法

有些程序（比如某些 Electron 应用）会把自己的窗口固定在屏幕中央，你摆它它也不听，
或者一摆就乱。与其每次都失败，不如加进排除表，眼不见为净。
