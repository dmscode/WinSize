窗口排除
========

有些窗口不希望 WinSize 碰，比如任务栏、全屏播放器、布局总是特殊的工具。把它们排除后，程序不会再摆它们，也不会把它们绑成书签。

## 用按键排除

1. 切到那个窗口，让它当前台。
2. 双击左 Alt，按 `U`。

提示 `Excluded.` 就说明加进去了。

同一个窗口再按一次 `U` 会取消排除，提示 `Unexcluded.`。这个操作是幂等的，不用去配置文件里删。

如果担心误按，可以在设置页的“按键”区把 `U` 清空。

## 规则写法

排除规则存在 `Config.ini` 的 `[Exclusions]` 节：

```ini
[Exclusions]
1 = D:\Program Files\Microsoft VS Code\Code.exe|Chrome_WidgetWin_1
```

每一行是 `进程|窗口类`：

| 段 | 含义 | 能不能省 |
| --- | --- | --- |
| 进程 | exe 的完整路径，或只写文件名 | 能，留空表示按类匹配所有进程 |
| 窗口类 | 窗口类名，Windows 的内部标识 | 能，留空表示该进程的所有窗口 |

前面的编号只用于排序，程序下次写入时会自动重排。

## 在设置页里改

托盘 → 设置 → 窗口排除。每条一行，两个输入框分别对应进程和窗口类，底部有“＋ 添加一条”。

比手改文件好在两点：写错了会当场提示，保存后立即生效。

## 内置排除

下面这些窗口是硬编码排除的，加不进用户列表，也删不掉：

| 窗口 | 原因 |
| --- | --- |
| 桌面（`Progman` / `WorkerW`） | 摆桌面没有意义 |
| 任务栏（`Shell_TrayWnd` 等） | 摆任务栏会让整个桌面错乱 |
| 托盘溢出面板 | 同上 |
| 开始菜单、小部件 | 系统 UI，摆了会出问题 |
| 通知中心、设置弹窗（`ShellExperienceHost`） | 系统 UI，闪现即走 |

在这些窗口上按 `U` 会提示 `No Window`，什么都不会发生。

## 排除之后

被排除的窗口：

| 影响 | 表现 |
| --- | --- |
| 不能作为布局目标 | 它是前台时双击 Alt，提示条变橙色，进入命令模式 |
| 不能绑定 | 按槽位键连它时会提示 `No Window Available` |
| 不参与悬停激活 | 鼠标停在上面不会切换过去 |

鼠标手势也一样。`LAlt + 右键` 点在被排除的窗口上不会有反应。

## 一个常见用法

有些程序会把窗口固定在屏幕中央，摆它也不听，或者一摆就乱。与其每次都失败，不如加进排除表。
