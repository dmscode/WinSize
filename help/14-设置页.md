设置页
======

所有能调的东西都在这里，不用手改 `Config.ini`。它是程序自己起的一个本地网页，
用系统默认浏览器打开。

## 怎么打开

| 入口 | 操作 |
| --- | --- |
| 托盘 | 右键图标 → 设置 |
| 冒号指令 | 双击 Alt → `Shift` + `;` → 输入 `set` 回车（也可以写 `opt`） |
| 自己绑一个键 | 默认没有占用字母键，想更快可以绑 `Settings`（见 [05](./05-按键绑定.md)） |

只有一个入口是**删不掉**的：托盘菜单里的设置项（这是故意的，见 [13](./13-托盘菜单.md)）。

## 页面结构

左边是导航，八个区：

| 区 | 管什么 |
| --- | --- |
| **常规** | 开机自启、六个全局开关，以及检查更新 |
| **窗口排除** | 哪些窗口不参与排版、绑定、悬停 |
| **布局** | 布局方案的名字与规则；AI 提示词入口 |
| **按键** | 键盘图 + 每个键的动作 |
| **冒号指令** | 能输入的所有指令（说明书，只读） |
| **插件** | 每个插件的开关与参数 |
| **托盘** | 托盘菜单的条目与顺序 |
| **快速布局** | 九宫格的九个格子各对应哪个方案 |

插件区里每个插件一个卡片：上面是**开关**（勾上就加载），下面是它的参数。

> **有两个插件只有开关，没有参数**：大写提示和窗口绑定。这不是缺项——
> 它们的行为要么由按键触发（`CapsLock`、`1`~`0`），要么在别处配置，确实没有可调的值。

## 检查更新

常规区最下面那一行管版本：

- **自动检查更新**（开关，默认开）：程序启动 60 秒后查一次，之后每 24 小时一次。
  发现新版本时**托盘菜单最上面**会多出一条「新版本 x.y.z 可用」，点它打开获取页面。
- **立即检查**（按钮）：不管开关怎么设都能用。检查期间显示「检查中…」，
  结果会写明"已是最新"或"发现新版本"；失败时会说清原因（超时 / 连不上 / 版本文件格式不对）。

程序**只读取一个记录版本号的小文件**，不下载安装包、不上传任何信息。
只有远端版本高于当前版本才提示，从不提示"降级"。

## 什么时候生效

这是最容易搞错的一点，分两类：

| 类型 | 例子 | 生效时机 |
| --- | --- | --- |
| **勾选框**（带 `立即生效` 标记的） | 开机自启、插件开关 | 勾完立即生效 |
| **其它所有改动** | 布局、按键、托盘、参数 | 点右上角「保存」之后 |

右上角的按钮会显示当前状态：

- `已保存`（灰）——没有未保存的改动；
- 有改动时按钮变亮并可点，页面上的卡片也会出现「未保存」徽标。

保存后**立即生效**：热键重新绑定、插件按新开关启停、托盘菜单重建。不需要重启程序，
也不需要手动重载。

## 非法输入会被整批拒绝

保存时先校验全部内容，只要有一处不合法就**整批不保存**，并指出是哪个字段、错在哪：

| 例子 | 提示 |
| --- | --- |
| 布局规则少了一段 | 格式应为 `x\|y\|宽\|高` |
| 宽高写成 0 | 宽高必须大于 0 |
| 按键引用了不存在的布局 | 没有这个布局 |
| 托盘点了个不存在的动作 | 没有这个动作 |
| 删掉一个还被按键引用的布局 | 按键 `Q` 还指向它，先改那个键 |

"整批拒绝"是刻意的：如果只保存一半，你会得到一份"改了但没完全改"的配置，
比直接失败更难排查。

## 那些需要重启的项

现在没有。

`[Server] IdleMs`（服务空闲多久自动关闭）改完会直接重应用，不需要重启。

## 安全性

设置页的地址长这样：

```
http://127.0.0.1:54321/settings.html?t=8f3a...
```

- **只监听回环地址**：同一局域网的手机、别的电脑都连不上。
- 地址里的 `t` 是本次运行的一次性票据，程序重启就换新的。
- **不要把这个地址发给别人**，也不要贴到公开的地方。能访问它就能改你的配置。
- 服务随程序启动就在监听，**永不自动关闭**（`[Server] IdleMs = 0`）。
  想让它空闲时收摊，把 `IdleMs` 改成一个毫秒值（如 `300000` = 5 分钟）。

## 页面打不开怎么办

| 现象 | 原因 |
| --- | --- |
| 浏览器显示无法连接 | 程序没在跑；或端口被占，看 `Debug.log` 里的 "本地服务启动失败" |
| 页面空白 / 404 | 程序目录缺 `web` 文件夹，重新解压发布包 |
| 提示目录不可写 | 程序放在没有写权限的位置，见 [01](./01-安装与启动.md) |
| 打不开设置，托盘也没有 | 程序没在运行；或被杀软拦了 |
