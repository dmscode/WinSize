设置页
======

所有能调的东西都在设置页里，不用手改 `Config.ini`。它是程序自己起的一个本地网页，用系统默认浏览器打开。

## 怎么打开

| 入口 | 操作 |
| --- | --- |
| 托盘 | 右键图标 → 设置 |
| 冒号指令 | 双击 Alt，按 `Shift` + `;`，输入 `set` 回车，也可以写 `opt` |
| 自己绑一个键 | 默认没有占用字母键，想更快可以绑 `Settings`，见 [05](./05-按键绑定.md) |

托盘菜单里的设置项删不掉。这是故意的，见 [13](./13-托盘菜单.md)。

## 页面结构

左边是导航，一共八个区，从上到下是：

| 区 | 管什么 |
| --- | --- |
| 常规 | 开机自启、五个全局开关、检查更新 |
| 布局 | 布局方案的名字与规则，规则写法与 AI 提示词入口 |
| 按键 | 键盘图和每个键的动作 |
| 快速布局 | 九宫格每个格子对应哪个方案 |
| 窗口排除 | 哪些窗口不参与排版、绑定、悬停 |
| 插件 | 每个插件的开关与参数 |
| 冒号指令 | 能输入的所有指令，只读 |
| 托盘 | 托盘菜单的条目与顺序 |

窗口较窄时，导航会移到页面顶部，可以左右滚动；内容仍在下方，设置项不变。

每个区内部按组分段。常规分成启动、窗口、界面、更新、诊断五组，组名在左，成组的按钮在组名右侧。

鼠标停在导航上，当前区下面会展开它包含的条目，点条目直接跳到那一行；条目少的区不展开。

导航顶部是搜索框。输入关键词后只留下名字或说明里含这个词的条目，命中的区自动展开，没命中的区连同它的导航项一起收起，搜索框下面显示命中几项；按 Esc 清空。

插件区里每个插件一组：组名是插件名，右边是开关和它的标识，下面是参数。勾上就加载，参数改完保存生效。

关闭的插件会留在列表里并标为“已停用”，重启后也能重新勾选打开，不需要手改配置。

大写提示和窗口绑定只有开关，没有参数。它们的行为要么由按键触发（`CapsLock`、`1`~`0`），要么在别处配置，确实没有可调的值。

## 键位用点选，不用背写法

按键区的单键绑定，和插件里窗口切换的两个快捷键，都是点选出来的：点键盘上一个键，再点需要的修饰键（左右 Ctrl、左右 Alt、左右 Shift、Win）。

窗口切换的两个键还会在上方把当前结果写成「左 Alt + 反引号」这样的标签，按固定的修饰键顺序排列，符号键显示符号本身、特殊键才写名字。

确实要手写时，写法与 [15 配置文件](./15-配置文件.md) 里的一致（例如 `<!q`、`<!<+q`）。

## 检查更新

常规区的「更新」组管版本，一行里三样东西：`自动检查更新` 勾选框、「检查更新」按钮、结果说明。

勾选框默认开着。每次打开设置页时，浏览器会读一次公开仓库的版本文件。发现新版本时，页面顶部出现升级提示，托盘菜单最上面同时多一条“【新版本 x.y.z 可用】”，点它打开获取页面。程序本身不在后台定时联网。

按钮不管勾选框怎么设都能用，点一次查一次。结果写在按钮后面，失败时会说明是连不上，还是版本文件格式不对。

升级提示会写出当前版本和最新版本，并列出这次改了什么，最多两条。另外还可能有琥珀色通知，比如活动、已知问题，最多两条，每条独立成块、可换行，这类通知不能点。

窗口较宽时，提示放在左侧栏底部，不挡内容。窗口变窄时自动回到页面顶部。

程序只读取一个记录版本号的小文件，不下载安装包，也不上传任何信息。只有远端版本高于当前版本才提示，从不提示降级。

不打开设置页就不会提示新版本。检测从后台每天查一次改成了打开设置页才查一次，为的是省掉常驻的网络栈内存。托盘显示的是上次查到的结果。

## 关掉页面前的确认

改过东西还没保存就关标签页，浏览器会弹一次确认，避免顺手关掉丢改动。

浏览器不允许自定义这段文字，看到的是它自带的那句；强行结束浏览器进程拦不住。

## 什么时候生效

| 类型 | 例子 | 生效时机 |
| --- | --- | --- |
| 旁边写着“立即生效”的开关 | 开机自启、插件开关 | 勾完立即生效 |
| 其它改动 | 布局、按键、托盘、参数 | 点右上角“保存”之后 |

右上角的按钮会显示当前状态：

- `已保存`（灰色）：没有未保存的改动。
- 有改动时按钮变亮并可点，页面上的卡片会出现“未保存”徽标。

保存后立即生效。热键重新绑定，插件按新开关启停，托盘菜单重建。不需要重启程序，也不需要手动重载。

## 非法输入会被整批拒绝

保存前会校验全部内容。只要有一处不合法，整批都不会保存，并指出是哪个字段、错在哪：

| 例子 | 提示 |
| --- | --- |
| 布局规则少了一段 | 格式应为 `x\|y\|宽\|高` |
| 宽高写成 0 | 宽高必须大于 0 |
| 按键引用了不存在的布局 | 没有这个布局 |
| 托盘点了个不存在的动作 | 没有这个动作 |
| 删掉一个还被按键引用的布局 | 按键 `Q` 还指向它，先改那个键 |

只保存一半会得到一份改了但没完全改的配置，比直接失败更难排查，所以这里选择整批拒绝。

## 需要重启的项

现在没有。

`[Server] IdleMs`（服务空闲多久自动关闭）改完会直接重新应用，不需要重启。

## 安全性

设置页的地址长这样：

```
http://127.0.0.1:54321/settings.html?t=8f3a...
```

- 只监听回环地址，同一局域网的手机、别的电脑都连不上。
- 地址里的 `t` 是本次运行的一次性票据，程序重启就换新的。
- 不要把这个地址发给别人，也不要贴到公开的地方。能访问它就能改你的配置。
- 服务随程序启动就在监听，默认永不自动关闭（`[Server] IdleMs = 0`）。想让它空闲时关闭，把 `IdleMs` 改成毫秒值，比如 `300000` 表示 5 分钟。

## 页面打不开怎么办

| 现象 | 原因 |
| --- | --- |
| 浏览器显示无法连接 | 程序没在跑，或者端口被占，看 `Debug.log` 里的“本地服务启动失败” |
| 页面空白或 404 | 程序目录缺 `web` 文件夹，重新解压发布包 |
| 提示目录不可写 | 程序放在没有写权限的位置，见 [01](./01-安装与启动.md) |
| 打不开设置，托盘也没有 | 程序没在运行，或者被杀软拦了 |
