辅助线
======

一条全屏横线或竖线跟着鼠标走，用来目测对齐。两三个窗口并排时，比眼睛估位置准。

## 怎么用

| 按键 | 结果 |
| --- | --- |
| `G` | 开关：显示 / 收起 |
| `-` | 只开横线 |
| `=` | 十字，横线加竖线 |
| `\` | 只开竖线 |

`-`、`=`、`\` 是直接切到对应模式并显示，不是切换。已经在显示时按 `-`，就变成只剩横线。

再按一次当前模式的键，或者按 `G`，收起。

## 启动时一定是关闭的

程序启动时辅助线不会自己出现，配置里也没有“启动就显示”的开关。

辅助线是临时工具，对齐完就该消失。如果开机就挂在屏幕上，很快就会变成干扰。

## 线的样子

| 特性 | 说明 |
| --- | --- |
| 跟随鼠标 | 移动鼠标，线跟着走 |
| 不抢焦点 | 线只是画在屏幕上，点下去仍然点到下面的窗口 |
| 有一个小缺口 | 十字交叉处断开一小段，能看清鼠标指着的那行字 |
| 只在鼠标所在屏 | 线横跨那块显示器 |

## 调样式

设置页 → 插件 → 辅助线，或者 `Config.ini` 的 `[Plugins.Guides]`：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 横线厚度 `Width` | 0 | 0 表示按系统文字行高自动取值（本机实测 30 像素，随字体与屏幕缩放变化），大致盖住表格一行；也可以写 1~96 的像素值 |
| 竖线厚度 `VWidth` | 0 | 0 表示跟横线同宽；也可以单独指定 |
| 不透明度 `Opacity` | 120 | 0~255，越小越淡 |
| 颜色 `Color` | `CCCC00` | 6 位十六进制，不带 `#`。默认暗黄，深色和浅色桌面上都看得见 |
| 缺口半径 `Gap` | 24 | 十字交叉处断开的像素半径；0 表示不断开，连成完整十字 |

改完在设置页保存即刻生效，不需要重启。

`VWidth = 0` 的意思是跟着横线走。设置页存的是原始值，不会把它固化成具体数字，所以以后改横线厚度，竖线会自动一起变。

## 它只负责显示

辅助线是独立的覆盖层，不改变任何窗口。它不会让窗口吸附到线上，也不会记住位置，只是让你看见线现在在哪，剩下的靠你自己对齐。

需要自动吸附，用鼠标手势的拖框，见 [04](./04-鼠标手势.md)。那边有网格，两端会自动对齐。
