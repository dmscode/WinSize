辅助线
======

一条全屏的横线（或竖线）跟随鼠标，用来目测对齐。两三个窗口并排时，比眼睛估位置准。

## 怎么用

| 按键 | 结果 |
| --- | --- |
| `G` | 开关：显示 / 收起 |
| `-` | 只要横线 |
| `=` | 十字（横 + 竖） |
| `\` | 只要竖线 |

`-`、`=`、`\` 是直接切到那种模式并显示，不是切换。已经在显示时按 `-`，就变成"只剩横线"。

再按一次当前模式的键，或按 `G`，收起。

## 启动时一定是关闭的

程序启动时辅助线**不会**自己出现，配置里也没有"启动就显示"的开关。这是设计，不是遗漏。

辅助线是临时工具：对齐完就该消失。如果开机就挂在屏幕上，很快就变成干扰。

## 线的样子

| 特性 | 说明 |
| --- | --- |
| 跟随鼠标 | 移动鼠标，线跟着走 |
| 不抢焦点 | 线只是画在屏幕上，点下去仍是点到下面的窗口 |
| 有一个小缺口 | 十字交叉处断开一小段，让你看清鼠标指着的那行字 |
| 只在鼠标所在屏 | 线横跨那块显示器 |

## 调样式

设置页 → 插件 → **辅助线**，或 `Config.ini` 的 `[Plugins.Guides]`：

| 项 | 默认 | 说明 |
| --- | --- | --- |
| 横线厚度 `Width` | 0 | `0` = 自动取系统文字行高（约 24 像素，正好盖住表格一行）；也可以写 1~96 的像素值 |
| 竖线厚度 `VWidth` | 0 | `0` = 与横线同宽；也可以单独指定 |
| 不透明度 `Opacity` | 120 | 0~255，越小越淡 |
| 颜色 `Color` | `CCCC00` | 6 位十六进制，**不带 `#`**。默认暗黄，深色和浅色桌面上都看得见 |
| 缺口半径 `Gap` | 24 | 十字交叉处断开的像素半径；`0` = 不断开（连成完整十字） |

改完在设置页保存即刻生效，不需要重启。

> `VWidth = 0` 的语义是"跟着横线走"。设置页存的是原始值，不会把它固化成具体数字，
> 所以以后改横线厚度，竖线会自动一起变。

## 为什么不干脆做成窗口边框

辅助线是**独立的覆盖层**，不改变任何窗口。它不会让窗口"吸附"到线上，也不会记住位置——
它只是让你看见"这条线现在在哪"，剩下的靠你自己对齐。

需要真正的吸附，用鼠标手势的拖框（[04](./04-鼠标手势.md)）：那边有网格，两端会自动对齐。
