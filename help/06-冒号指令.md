冒号指令
========

键位有限，不常用的动作不必占一个键。冒号指令可以直接输入动作名来执行。

## 怎么用

1. 双击左 Alt，出现等待条。
2. 按 `Shift` + `;`，也就是打出一个冒号，提示条变成 `: `。
3. 输入指令，按回车。

输入时会浮出一列候选，只列不需要参数的动作。可以用 `↑` `↓` 或 `Tab` 移动选择。

- 什么都不输入，直接回车，执行当前选中项。
- 输入了内容但程序不认，比如只打了两个字母，也会回退到选中项。

`Esc` 分两级：有内容时先清空，已经空了再按才退出。

## 能输入什么

程序按优先级匹配，整串命中优先，所以 `Center` 这种布局名不会被空格切坏。

| 输入 | 结果 |
| --- | --- |
| 动作名或别名，比如 `reload`、`Reload`、`hv` | 执行该动作（**要写全，不支持前缀缩写**） |
| 布局名，比如 `Center` | 套用该布局 |
| `pin` 或 `top` | 置顶开关 |
| `动作名 参数`，比如 `wb 3`、`g h` | 带参数执行 |

参数原样交给动作解释。不合法时提示 `Error Action`，不会静默当成开关处理。

## 常用指令

| 指令 | 作用 |
| --- | --- |
| `set` / `opt` / `option` / `settings` | 打开设置页 |
| `reload` | 重读 `Config.ini` |
| `reboot` | 重启程序 |
| `help` | 打开帮助 |
| `version` | 显示版本 |
| `pin` / `top` | 窗口置顶开关 |
| `exclude` | 排除 / 取消排除当前窗口 |
| `Center` / `FullLeft` 等 | 套用同名布局，直接打方案名即可 |
| `g` / `guide` | 辅助线开关 |
| `g h` / `g v` / `g x` | 只开横线 / 只开竖线 / 十字 |
| `hv` / `hover` | 悬停激活开关 |
| `wb 3` | 绑定或唤回 3 号槽位的窗口 |
| `wu 3` | 强制解绑 3 号槽位 |

指令清单不是手抄的。设置页的“冒号指令”区会按当前动作注册表实时生成，关掉某个插件后，它提供的指令会从列表里消失。

## 什么时候用

| 场景 | 例子 |
| --- | --- |
| 布局方案多到键位不够 | 二十个方案只有九个常用，其余打名字 |
| 不常用的动作 | 重启、看版本、开设置 |
| 带参数的动作用得少 | 一年绑一次的槽位，不值得占键 |

日常摆窗口仍然按单键最快。冒号指令适合放不常按的动作。

## 注意

- 输入期间程序不拦截其它键盘。按 `Esc` 或回车后立刻恢复，不会卡住。
- 中文输入法下也能进入输入态，`Shift+;` 已经验证过。但指令本身要用英文打。
- 输入态没有超时，它会一直等你操作。忘了退出就按 `Esc`。
