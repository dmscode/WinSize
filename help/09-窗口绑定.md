窗口绑定
========

把窗口存成一个书签，按一个数字键随时把它叫回前台。十个槽位：`1`~`9` 和 `0`。

## 三种操作，一个键

切到目标窗口 → 双击左 Alt → 按一个数字：

| 当前状态 | 按下去的结果 |
| --- | --- |
| 这个槽位**空着** | 把当前窗口绑上去（提示 `Bind 3`） |
| 槽位绑的是**别的**窗口 | 把那窗口叫到前台 |
| 槽位绑的就是**当前**窗口 | 解绑（提示 `Unbind 3`） |

不用记"我该按几下"——状态决定行为，按错了最多是多按一次就解绑，再按一次又绑回来。

## 举个完整的例子

1. 打开你的编辑器，切到它，双击 Alt，按 `1` → `Bind 1`。
2. 打开浏览器，切到它，双击 Alt，按 `2` → `Bind 2`。
3. 现在无论在哪，双击 Alt 按 `1`，编辑器跳到前面；按 `2`，浏览器跳到前面。

想**换掉** `1` 号槽里存的窗口时，直接在新窗口按 `1` 是不行的——那只会把旧窗口叫回前台。
需要先解绑，两种办法：

| 办法 | 步骤 |
| --- | --- |
| 用指令（快） | 双击 Alt → `Shift` + `;` → 输入 `wu 1` 回车，然后在新窗口按 `1` |
| 用按键 | 双击 Alt 按 `1` 唤回旧窗口 → 在旧窗口上再按一次 `1` 解绑 → 切到新窗口按 `1` |

## 记录会"跟着走"

唤回成功之后，如果实际唤回的窗口和记录里的不是同一个（原窗口关了、程序重开了一个新实例），
**记录会更新成新窗口**。

这带来一个实用效果：系统重启之后，只要那个程序重新打开，槽位就能重新接上，
不用重新绑一次。

## 唤回的匹配规则

依次尝试：

1. **原来那个窗口**（句柄还对得上就用它，最精确）；
2. 关掉了？按"同一个程序 + 同一个窗口类"找，找到就用最靠前的那个；
3. 一个都没有 → 清空槽位，提示 `SLOT CLEARED`。

第 2 步意味着：**开着多个同类窗口时，唤回哪一个不确定**（通常是最近创建的那个）。
如果这让你困扰，把不常用的同类窗口关掉，或者接受"它总是给你一个同类窗口"。

## 什么情况下会丢

| 情况 | 结果 |
| --- | --- |
| 关掉那个窗口 | 下次按提示 `SLOT CLEARED`，槽位清空 |
| 程序（WinSize）重启 | 记录还在，正常工作 |
| 系统重启 | 记录还在；那程序重开就能接上，没重开就等它重开或自动清空 |
| 那个程序整个卸载了 | 按到时清空 |

绑定记录写在 `Config.ini` 的 `[Plugins.WinBind]` 里，包含窗口标题，所以
**文档名或网页标题也会被记下来**。介意的话可以在退出前把槽位解掉，
或者换用别的办法（比如把窗口固定到任务栏）。

## 用指令

不带参数键位也能用：

```
wb 3    绑定或唤回 3 号槽（同按键）
wu 3    强制解绑 3 号槽
```
