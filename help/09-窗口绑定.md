窗口绑定
========

把窗口存成一个书签，按一个数字键随时叫回前台。一共十个槽位：`1`~`9` 和 `0`。

## 三种操作，一个键

切到目标窗口，双击左 Alt，按一个数字：

| 当前状态 | 按下去的结果 |
| --- | --- |
| 槽位空着 | 把当前窗口绑上去，提示 `Bind 3` |
| 槽位绑的是别的窗口 | 把那个窗口叫到前台 |
| 槽位绑的就是当前窗口 | 解绑，提示 `Unbind 3` |

不用记该按几下，状态决定行为。按错了最多是多按一次解绑，再按一次又绑回来。

## 一个完整的例子

1. 打开编辑器，切到它，双击 Alt，按 `1`，提示 `Bind 1`。
2. 打开浏览器，切到它，双击 Alt，按 `2`，提示 `Bind 2`。
3. 之后无论在哪，双击 Alt 按 `1`，编辑器到前面；按 `2`，浏览器到前面。

想换掉 `1` 号槽里的窗口，直接在新窗口按 `1` 不行，那只会把旧窗口叫回前台。需要先解绑，有两种办法：

| 办法 | 步骤 |
| --- | --- |
| 用指令，快一些 | 双击 Alt，按 `Shift` + `;`，输入 `wu 1` 回车，然后在新窗口按 `1` |
| 用按键 | 双击 Alt 按 `1` 唤回旧窗口，在旧窗口上再按一次 `1` 解绑，然后切到新窗口按 `1` |

## 记录会跟着窗口走

唤回成功后，如果实际唤回的窗口和记录里的不是同一个，比如原窗口关了、程序重开了一个新实例，记录会更新成新窗口。

这带来一个实用效果：系统重启后，只要那个程序重新打开，槽位就能重新接上，不用重新绑一次。

## 唤回的匹配规则

依次尝试：

1. 原来那个窗口。句柄还对得上就用它，最精确。
2. 关掉了，就按“同一个程序 + 同一个窗口类”找，找到就用窗口层叠顺序最靠上的那个。
3. 一个都没有，清空槽位，提示 `SLOT CLEARED`。

第 2 步意味着：开着多个同类窗口时，唤回哪一个不确定，通常是最近用过、压在其它同类窗口上面的那个。如果这让你困扰，把不常用的同类窗口关掉，或者接受它总是给你一个同类窗口。

## 什么情况下会丢

| 情况 | 结果 |
| --- | --- |
| 关掉那个窗口 | 下次按提示 `SLOT CLEARED`，槽位清空 |
| WinSize 重启 | 记录还在，正常工作 |
| 系统重启 | 记录还在；程序重开就能接上，没重开就等它重开或自动清空 |
| 那个程序卸载了 | 按到时清空 |

绑定记录写在 `Config.ini` 的 `[Plugins.WinBind]` 里，包含窗口标题，所以文档名或网页标题也会被记下来。介意的话，可以在退出前把槽位解掉。

## 用指令

不带参数的键位也能用：

```
wb 3    绑定或唤回 3 号槽
wu 3    强制解绑 3 号槽
```
