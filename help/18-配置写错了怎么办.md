# 18 配置写错了怎么办

`Config.ini` 是纯文本，你可以直接改，AI 也能替你改。但**改错了程序不会崩**，
它会跳过错的那几项继续运行——代价是那些功能悄悄失效，很容易让人以为"程序坏了"。

所以从 6.0 起，程序启动时会先体检一遍配置：**只要发现错误，就用浏览器打开一份清单**，
逐条告诉你是第几行、错在哪、怎么改。

## 你会看到什么

程序启动后，浏览器多出一个标签页，标题类似「配置有 3 处问题」：

```
配置有 3 处问题
程序已跳过下面这些项，其余功能正常。改好之后重启程序即可。
配置文件：F:\WinSize\Config.ini

第 37 行
[Layout] LeftTop
布局规则不合法：「0|0|50sw」
  怎么改：x|y|宽|高[|显示器]；例 0|0|50sw|50sh
  例子：0|0|50sw|50sh
  看相关文档 →
```

同时**托盘菜单最上面**会多一条 `【配置有 3 处问题，点此查看】`，随时可以再看一遍。

## 三件事要记住

**一、程序不会因此退出。** 只有一两处写错时，其余功能完全正常；
连配置文件都读不到时，程序会用**内置的默认配置**运行，清单页会写明这一点。

**二、清单每次启动重新生成。** 改好之后重启程序，页面和托盘那条一起消失。
不用手动删文件，也不用管它在哪。

**三、清单里的「看相关文档」直接带你到对应那一篇。** 比如布局串写错了就跳到
《03 布局方案》，按键动作写错了就跳到《05 按键绑定》。

## 最常见的几种错

| 你写的 | 问题 | 正确写法 |
| --- | --- | --- |
| `Left = 0\|0\|50sw` | 只有 3 段 | `Left = 0\|0\|50sw\|50sh` |
| `Left = 0\|0\|50%` | 单位不认识 | 百分比写 `sw`/`sh`，不是 `%` |
| `Q = LeftTop` | 把布局名当动作用了 | `Q = Layout\|LeftTop` |
| `Q = 置顶` | 动作名不用中文 | 见《05 按键绑定》的动作表 |
| `ShowTime = yes` | 开关只认 0 和 1 | `ShowTime = 1` |
| `1 = act:没有这个动作` | `[Tray]` 引用了不存在的动作 | `1 = act:pin` |
| 第一行就写 `Q = Layout\|A` | 没有先写 `[Keys]` | 每节以 `[节名]` 开头 |

## 让 AI 改配置时的一句话

把《15 配置文件》整篇贴给 AI，并加一句：

> 只输出完整的 ini 文件内容，不要解释，不要代码块。节名和键名必须是我文档里出现过的。

AI 写完你自己贴回 `Config.ini`，重启程序。**如果它写错了，体检清单会立刻告诉你第几行**，
把那段清单再贴回给 AI，它自己就能改对。

## 别忘了还能用设置页

大部分内容不需要手改文件。托盘右键 → 设置，在网页里改完点保存，
程序会**先校验再写盘**，写错的值当场标红，根本进不了文件。
手改只适合两种情况：批量改很多东西，或者想用 AI 一次生成一整份。
